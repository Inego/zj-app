# UI icons (chrome)

How to add a **tintable outline icon** for menus, reference chrome, and inline
help controls. Tile art and decorative sprites are out of scope.

For the **application** icon (launcher, taskbar, favicon, splash) see
[`app-icons.md`](app-icons.md) — different sources, different pipeline.

## Conventions

| Piece | Location / rule |
|--------|------------------|
| Source family | [Lucide](https://lucide.dev/) outline icons (prefer Feather-derived names already listed in the Lucide LICENSE when possible) |
| SVG source | `third_party/lucide-icons/<name>.svg` |
| Runtime PNG | `assets/ui/<snake_name>.png` |
| Loader | `core/.../render/ui/UiIcons.kt` |
| Attribution | `third_party/lucide-icons/ATTRIBUTION.txt` (+ `LICENSE` already vendored) |
| Asset index | `assets/assets.txt` — regenerated by Gradle `generateAssetList` on `processResources`; no hand edit required |

**PNG style:** white-on-transparent outline, **128×128**, linear-filter friendly.
In-game color comes from `SpriteBatch.setColor` (normal / hover / disabled).
Do not bake brand colors into the PNG.

**Naming:** Lucide slug in SVG (`info.svg`); snake_case under `assets/ui/`
(`info.png`, `chevron_left.png`). Map Lucide → file in ATTRIBUTION.

Do **not** introduce a second icon set or ad-hoc colored PNGs for chrome
unless there is a strong reason — keep everything tintable through `UiIcons`.

## Checklist (add one icon)

1. **Pick the glyph** on lucide.dev (outline, 24 viewBox, stroke 2).
2. **Vendor the SVG**  
   `https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/<name>.svg`  
   → `third_party/lucide-icons/<name>.svg`
3. **Rasterize** to white-on-transparent 128×128 PNG → `assets/ui/<snake_name>.png`  
   Match existing exports (`close.png`, `info.png`, …). Supersample then
   downscale if your tool stairs the strokes.
4. **ATTRIBUTION.txt** — add the Lucide name → `assets/ui/...` line; if the
   glyph is on the Feather-derived list in `LICENSE`, the MIT note already
   covers it (extend the prose list of names there as needed).
5. **`UiIcons`** — private `Texture?`, public getter, load in `ensureLoaded()`,
   dispose + null in `dispose()`. Keep lazy load (unit tests / early `Main`
   construction must not touch `Gdx.files` until first use).
6. **Use it**
   - Draw with batch tint only, or
   - Reuse / extend a control:
     - **Rimmed** square chrome: `CloseButton` (× / ←)
     - **Rimless** help affordance: `InfoButton` (i)
7. **Build** once so `assets.txt` includes the new PNG
   (`./gradlew :lwjgl3:run` or any task that runs `processResources`).

## Controls that consume icons

| Control | Look | Typical use |
|---------|------|-------------|
| `CloseButton` | Fill + rim + glyph | Panel exit / history back / game menu |
| `CollapseButton` | Fill + rim + chevron | Fold a panel body closed / open |
| `InfoButton` | Glyph-first, soft hover fill, **no rim** | Deep-link / help next to a label |

New reusable chrome should live under `core/.../render/ui/` and load glyphs
only through `UiIcons`.
