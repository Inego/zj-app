## Scoring notes (applies to all)

- Count across different series; one pattern per series (except 3.1 per set).
- Series = same first two number levels (e.g. 4.2.x is one series).
- Irregular hands (10.x): do **not** count 1.2 Concealed Hand.
- Seven Pairs: cannot count patterns that require triplets/kong/sequences; may count others (e.g. pure/mixed one-suit, terminals, honors).
- Prevailing wind: **not** recognized. Only seat wind + dragons for 3.1.

### Concealed triplet definition (series 4.2)

- **Concealed:** all three tiles from wall (including self-draw win tile).
- **Exposed:** one tile claimed (pong or win-on-discard); two from wall.
- Win-on-discard of the completing tile → that triplet is **exposed**.
