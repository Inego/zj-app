# Glossary (compact)

Sources: book App A (partial) + pattern pages + App C.

## Play

| term | zh | meaning |
|---|---|---|
| win / go out | 和牌 | Complete a winning hand |
| self-draw | 自摸 | Win by drawing own tile |
| win on discard | 銃和 | Win on another's discard |
| discarder | 銃家 / 放銃 | Player who discarded winning tile |
| call / ready | 聽牌 | One tile from complete |
| multi-wait | 多扉聽 | Multiple winning tile types |
| sequence / chow | 順子 / 吃 | 3 consecutive same suit |
| triplet / pong | 刻子 / 碰 | 3 identical |
| kong | 槓 | 4 identical declared + supplement |
| eyes / pair | 眼 / 對 | Pair completing regular hand |
| meld / claim | 鳴牌 | Chi/pong/kong from discard |
| upper / lower seat | 上家 / 下家 | Previous / next in turn order |
| concealed / exposed | 暗 / 明 | From wall only vs includes claim |
| dead wall | 王牌 | Reserved end tiles (ZJ: 14) |
| seabed | 海底 | Last live wall tile |
| riverbed | 河底 | Last discard after seabed |
| supplement | 嶺上 | Tile drawn after kong |
| intercept | 截和 | Seat-priority multi-win-on-discard resolution |
| no-win / draw | 流局 / 荒牌 | Hand ends without winner |
| false win | 錯和 | Illegal declared win |

## Scoring (ZJ)

| term | zh | meaning |
|---|---|---|
| pattern | 和種 / 番種 | Scoring condition + fixed points |
| series | 系列 | Mutual-exclusion group within category |
| category | 種類 | Top-level pattern family (1–10) |
| chicken hand | 雞和 | Winning regular hand with no patterns → 1 pt |
| additive rule | 複合加算 | Sum patterns across series |
| freedom of count | 自由數和 | Choose one tile arrangement to score |
| fixed income | 固定收入原則 | Winner total = f(V) only; no self-draw inflate |
| formal competition scheme | 中庸競技制 | Winner always 3V; big-hand discarder pays rest |
| standard score | 標準分數 | 25; equal-split threshold for win on discard |
| same-round immunity | 跟張免責 | Follow same discard → not responsible |
| compound limit | 數滿貫 | Sum ≥320 → score 320 |
| listed limit | 役滿貫 / 例牌 | Single pattern ≥320 → that pattern only |
| value honor | 番牌 | Seat wind or dragon triplet/kong |
| seat wind | 門風 / 自風 | Player's own wind |
| prevailing wind | 場風 / 圈風 | **Not used** in ZJ |
| basic points | 副底 / 和底 | Not used in standard ZJ |

| term | zh | meaning |
|---|---|---|
