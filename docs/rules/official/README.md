## v3.3 deltas (from book notes)

1. Payoff "standard score" = **25** (was different in earlier versions).
2. Pure One-Suit (清一色) = **80**.

## Core numbers

- Patterns: **44** in **10** categories (optional cat 11 flowers for casual).
- Chicken hand: **1** pt (standard; no min).
- Optional min: **5** pt.
- Limit (compound): **320**.
- Winner total income (formal scheme): always **3 × hand value**.
- No prevailing wind; seat wind + dragons are value honors.
- No faan/multiplicative system; pure additive by series.
