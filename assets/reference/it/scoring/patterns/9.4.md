# Benedizioni

**9.4** · 天地和

Benedizioni sulla primissima distribuzione: Cielo per le 14 iniziali di Est, Terra per una vittoria non di Est sul primo scarto di Est. Non valide se Est ha dichiarato un kong chiuso.
