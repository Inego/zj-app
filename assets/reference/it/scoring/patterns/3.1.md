# Onore di valore

**3.1** · 番牌 · [hl]**10 punti / combinazione**[/]

Tris o kong del tuo **[vento di posto](rules-seats)** o di qualsiasi
**[drago](rules-dragons)**. Si conta **cumulativamente per combinazione** (+10 ciascuno).
Non esiste **nessun** [vento prevalente](rules-seats) nello Zung Jung. Le
**tessere** dei venti: [Venti](rules-winds).

Si somma sempre con [Piccoli tre draghi](pattern-3.2.1) /
[Grandi tre draghi](pattern-3.2.2) e le [figure dei venti](pattern-3.3)
quando anche queste si applicano (ad es. [Grandi tre draghi](pattern-3.2.2)
include sempre 3× Onore di valore → almeno 160).
