# Setovi i oči

**Standardna ruka** se sastoji od **setova** i **očiju** (jednog para). Pogledajte
[Standardne i nestandardne ruke](rules-hands).

Svaki set je jedan od sledećih:

- **[Sekvenca](rules-sequence)** — tri uzastopna broja u istoj [boji](rules-suits)
- **[Trojka](rules-triplet)** — tri identične pločice
- **[Kong](rules-kong-types)** — četiri identične pločice, objavljene

Plus par koji završava ruku:

- **[Oči](rules-eyes)** — dve identične pločice (nisu set)

:::center
{123m} · {333p} · {1111s} · {55p}
:::

Kongovi se računaju kao setovi nakon što se objave i zahtevaju
[dopunsko vučenje](rules-kong-types). Uzimanje setova od odbačenih pločica
objašnjeno je u odeljku [Prijave pločica](rules-claims).
