# Reclamações

No **descarte fresco** de outro jogador (não uma peça mais antiga no rio),
você pode **reclamá-la** se ela completar um grupo ou uma vitória.

## Chow

- Completar uma [sequência](rules-sequence) usando a peça descartada.
- Apenas do **assento superior** (o jogador que descarta imediatamente
  antes de si — à sua esquerda nos diagramas de assentos padrão).
- Após um chow: expor a combinação, depois descartar; o jogo continua a
  partir de si.

## Pung

- Completar uma [trinca](rules-triplet) usando a peça descartada.
- De **qualquer** jogador.
- Após um pung: expor a combinação, depois descartar; o jogo continua a
  partir de si (os jogadores intervenientes passam).

## Kong (a partir de descarte)

- **Kong exposto grande:** tem uma trinca oculta; reclama a quarta de um
  descarte. Ver [Kong](rules-kong-types).

## Vitória

- Reclamar o descarte para completar uma forma vencedora legal
  ([Como vencer](rules-winning)).
- Prioridade mais alta sobre as reclamações de grupo.

## Prioridade de reclamação

Quando vários jogadores querem o mesmo descarte:

1. **Vitória** (mais alta)
2. **Pung** ou **kong exposto grande**
3. **Chow** (mais baixa)

Se vários jogadores reclamam uma **vitória**, a
[interceção](rules-winning) resolve quem a leva (ordem de assentos em
relação a quem descartou). O Zung Jung padrão usa a interceção clássica
de vencedor único, não múltiplas vitórias num único descarte.
