# Olhos (par)

Duas peças **idênticas** que completam uma mão regular (o “par” /
“olhos”).

:::center
{55s} · {WW}
:::

Os olhos **não** são um grupo. Precisa de exatamente um par numa
[mão regular](rules-hands) (a menos que vença com uma forma irregular
como [Sete Pares](pattern-10.2)).

Os olhos podem ser de qualquer desenho — números, [ventos](rules-winds)
ou [dragões](rules-dragons). Os padrões de pontuação às vezes interessam-se
pelo que os olhos são (por exemplo, olhos de honra bloqueiam
[Sem Terminais (1.3)](pattern-1.3)), mas a forma da mão em si só precisa
de um par.
