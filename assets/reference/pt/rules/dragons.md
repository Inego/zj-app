# Dragões

Três desenhos de **[honra](rules-honors)** — não um [naipe](rules-suits)
numerado:

:::center
{P}{F}{C}
:::

- **Branco** (白) — {P}
- **Verde** (發) — {F}
- **Vermelho** (中) — {C}

Os dragões não têm ordem de classificação. Não podem formar
[sequências](rules-sequence) — apenas [trincas](rules-triplet) ou
[kongs](rules-kong-types) do **mesmo** desenho (três Vermelhos, não “um
de cada dragão”).

Qualquer trinca ou kong de dragão é sempre uma
[Honra de Valor (3.1)](pattern-3.1) (+10 por grupo), para todos os
jogadores.
