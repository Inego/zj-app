# Trinca

Três peças **idênticas** (mesmo desenho).

:::center
{333p} · {EEE} · {CCC}
:::

[Ventos](rules-winds) e [dragões](rules-dragons) só formam trincas (ou
kongs) do **mesmo** desenho — não um “grupo de todos os ventos” ou “grupo
de todos os dragões”. Ter um de cada vento ({E}{S}{W}{N}) ou um de cada
dragão ({P}{F}{C}) são apenas três ou quatro peças diferentes, não um
grupo. Precisa de três Lestes para uma trinca de Leste, três Vermelhos
para uma trinca de dragão Vermelho, e assim por diante.

(Os padrões de pontuação como [Grandes Quatro Ventos (3.3.4)](pattern-3.3.4)
ainda exigem verdadeiras **trincas** de vento — recolher um de cada não
basta.)

Reclamar a terceira cópia a partir do descarte de qualquer jogador é um
**pung**. Ver [Reclamações](rules-claims).

Quatro peças idênticas declaradas como grupo são um
[kong](rules-kong-types), não uma trinca mais longa.
