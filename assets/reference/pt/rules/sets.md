# Grupos e olhos

Uma **mão regular** é construída a partir de **grupos** mais **olhos**
(um par). Ver [Mãos regulares e irregulares](rules-hands).

Cada grupo é um de:

- **[Sequência](rules-sequence)** — três números consecutivos, mesmo [naipe](rules-suits)
- **[Trinca](rules-triplet)** — três peças idênticas
- **[Kong](rules-kong-types)** — quatro peças idênticas, declaradas

Mais o par de conclusão:

- **[Olhos](rules-eyes)** — duas peças idênticas (não é um grupo)

:::center
{123m} · {333p} · {1111s} · {55p}
:::

Os kongs contam como grupos após serem declarados e exigem uma
[compra de suplemento](rules-kong-types). Reclamar grupos a partir de
descarte é abordado em [Reclamações](rules-claims).
