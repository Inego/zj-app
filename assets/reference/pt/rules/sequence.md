# Sequência

Uma sequência é **exatamente três** números consecutivos no
**mesmo [naipe](rules-suits)**. As honras não podem formar sequências.

:::center
{123m} · {567p} · {789s}
:::

Uma série mais longa **não** é “uma sequência melhor”. Por exemplo {3456m}
são quatro peças, não um grupo: ainda precisa de as agrupar como **duas**
peças da mão (por exemplo uma sequência {345m} com um {6m} extra, ou
{456m} com um {3m} extra). Essas quatro peças nunca contam como uma única
sequência de quatro peças.

Apenas **3** em fila é um grupo. Apenas **3** peças idênticas é uma
[trinca](rules-triplet) (e apenas **4** idênticas é um
[kong](rules-kong-types) — um tipo diferente de grupo, não uma sequência
mais longa).

Reclamar uma sequência a partir de um descarte é um **chow** (apenas do
jogador à sua esquerda — o assento superior). Ver
[Reclamações](rules-claims).
