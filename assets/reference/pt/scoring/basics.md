# Fundamentos da Pontuação

Zung Jung é um sistema aditivo **baseado em padrões** (v3.3). Apenas a
mão vencedora é pontuada. Não há piso básico de pontos (副底): o
valor da mão é a soma apenas dos valores dos padrões.

## Regra aditiva

- Conte padrões de **séries diferentes**.
- Dentro da mesma série, conte **apenas um** (geralmente o maior
  que se aplica).
- **Exceção — [Honra de Valor (3.1)](pattern-3.1):** +10 **por** grupo qualificado;
  acumula com outros padrões de honra.

Séries compartilham os dois primeiros níveis de ID (por exemplo, todos os [4.2.x](pattern-4.2) são uma
série). Veja a página de cada padrão para as notas de sua série.

## Mão sem figura

Uma [mão regular](rules-hands) completa **sem** padrões de pontuação
vale [hl]**1**[/] ponto — veja [Mão sem figura](scoring-chicken-hand).
Não há mínimo no Zung Jung padrão (um mínimo opcional de 5 pontos
existe como variante).

## Limites

- **Limite composto:** se vários padrões somam 320 ou mais, a
  mão pontua [hl]**320**[/] (os padrões ainda estão conceitualmente presentes).
- **Limite listado:** um único padrão listado em 320+ pontua **apenas
  esse padrão** (nada mais é adicionado). O maior padrão listado
  vence se vários se aplicarem.

## Pagamento (formal)

O vencedor sempre recebe **3 × valor da mão**.

- **[Compra própria](rules-winning):** cada um dos outros três paga o valor total da mão.
- **[Vitória por descarte](rules-winning), valor ≤ 25:** cada um dos três paga o
  valor total da mão.
- **Vitória por descarte, valor > 25:** cada jogador não responsável paga
  **25**; quem descartou paga **3×valor − 50**.

Nenhum [vento predominante](rules-seats) é reconhecido. [Vento do assento](rules-seats) e
[dragões](rules-dragons) são as honras de valor para o padrão
[3.1](pattern-3.1).
