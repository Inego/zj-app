# Драконы

Три **[благородных](rules-honors)** рисунка — не номерная
[масть](rules-suits):

:::center
{P}{F}{C}
:::

- **Белый** (白) — {P}
- **Зелёный** (發) — {F}
- **Красный** (中) — {C}

У драконов нет порядка рангов. Они не образуют [чоу](rules-sequence)
— только [панги](rules-triplet) или [конги](rules-kong-types) **одного**
рисунка (три Красных, а не «по одному каждого дракона»).

Любой панг или конг дракона всегда
[Ценные благородные (3.1)](pattern-3.1) (+10 за сет) для **любого**
игрока.
