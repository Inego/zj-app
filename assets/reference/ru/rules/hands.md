# Стандартные и нестандартные руки

Чтобы выиграть, рука должна соответствовать законной **форме
выигрыша**. Комбинации категорий 1–9 **не** создают других форм —
они только оценивают уже полную руку.

## Стандартная рука

**Четыре сета** + **одна пара**.

Каждый сет — [чоу](rules-sequence), [панг](rules-triplet) или
[конг](rules-kong-types). К четырём сетам нужна завершающая
[пара](rules-eyes). Объявленный конг
считается сетом.

### Рука без комбинаций

Полная стандартная рука **без** очковых комбинаций — законный
выигрыш в стандартном Чжун-юн: [рука без комбинаций](scoring-chicken-hand)
даёт [hl]**1**[/] очко.

Некоторые игроки и турниры запрещают руки без комбинаций (считают
ложными выигрышами). Этот вариант поддержан в приложении в
настройках партии (**Разрешить руки без комбинаций**).

## Нестандартные руки (Чжун-юн)

Без формы «четыре сета + пара» можно выиграть только формами из
[Нестандартных рук (10)](pattern-10):

- [Тринадцать сирот (10.1)](pattern-10.1)
- [Семь пар (10.2)](pattern-10.2)

Примеры, где всё равно нужна стандартная форма (или семь пар):

- [Все благородные (3.4)](pattern-3.4) — все кости благородные, но
  всё равно четыре сета + пара **или** семь пар
- [Все панги (4.1)](pattern-4.1) — четыре панга/конга + пара
