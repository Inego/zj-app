# Сеты и пара

**Стандартная рука** строится из **сетов** и **пары** (глаз). См.
[Стандартные и нестандартные руки](rules-hands).

Каждый сет — один из:

- **[Чоу](rules-sequence)** — три подряд идущих номера одной [масти](rules-suits)
- **[Панг](rules-triplet)** — три одинаковые кости
- **[Конг](rules-kong-types)** — четыре одинаковые кости, объявленные

Плюс завершающая пара:

- **[Пара (глаза)](rules-eyes)** — две одинаковые кости (не сет)

:::

Объявленный конг считается сетом и требует
[добавочной кости](rules-kong-types). Объявления сетов со сбросов —
в [Объявлениях](rules-claims).
