# Ветры

Четыре **[благородных](rules-honors)** рисунка — не номерная
[масть](rules-suits):

:::center
{E}{S}{W}{N}
:::

- **Восток** (東)
- **Юг** (南)
- **Запад** (西)
- **Север** (北)

У ветров нет порядка рангов. Они не образуют [чоу](rules-sequence) —
только [панги](rules-triplet) или [конги](rules-kong-types) **одного**
рисунка (три Востока, а не «по одному каждого ветра»).

## Ветер места и кость

У каждого игрока есть **[ветер места](rules-seats)** по его месту.
Панг или конг **вашего** ветра места даёт
[Ценные благородные (3.1)](pattern-3.1). Ветры мест других игроков для
вас ценными благородными не считаются.

В Чжун-юн **нет** превалирующего (кругового / столового) ветра.

## Очковые комбинации
