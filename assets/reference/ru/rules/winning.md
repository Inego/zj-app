# Как выигрывают

Выигрыш — завершение законной [формы руки](rules-hands) и
объявление. Откуда пришла последняя кость, влияет на процедуру и
на некоторые [случайные комбинации (9)](pattern-9).

## Готовность (слушание)

Рука **готова** (слушает), когда до законного выигрыша **одна
кость** — возможно, несколько типов костей (многосторонняя
ожидание).

Пример: [Девять врат (2.2)](pattern-2.2) — известное девятистороннее
ожидание одной [масти](rules-suits).

## Взятие со стены

Завершающую кость берёте со стены сами. Сбросившего нет. Выплата:
каждый из троих платит полную стоимость — см.
[Основы подсчёта](scoring-basics).

## Выигрыш на сбросе

Забираете чужой сброс как завершающую кость. Этот игрок —
**сбросивший** (часто «ответственный» плательщик на крупных
руках). Сет, завершённый этой костью, [открыт](rules-concealed-open).

## Ограбление конга

Когда кто-то объявляет **малый открытый конг**, если добавленная
кость завершает ваш выигрыш, можно забрать её
([Ограбление конга (9.3)](pattern-9.3)). Для выплат это
**выигрыш на сбросе**. **Закрытый** конг ограбить нельзя (в том
числе тринадцатью терминалами).

## Перехват

Если выигрыш на один сброс заявляют несколько игроков, победитель
один — по порядку мест от сбросившего: **нижний** (следующий по
ходу) выше напротив, тот выше верхнего. В стандартном Чжун-юн нет
нескольких победителей на один сброс.
