# Конг

**Конг** — четыре одинаковые кости, **объявленные** как сет. После
любого объявления конга берут **добавочную** кость, затем обычно
сбрасывают — если только добавочная не выигрывает
([Выигрыш на замене конга (9.2)](pattern-9.2)).

## Закрытый конг

Все четыре в руке; объявляете. В Чжун-юн четыре кости показывают
для проверки. Закрытый конг **не** ломает
[Закрытую руку (1.2)](pattern-1.2).

Закрытый конг **нельзя** ограбить.

## Большой открытый конг

В руке **закрытый** панг; четвёртая кость — со сброса. Конг
открытый.

## Малый открытый конг

Уже есть **открытый панг**; четвёртая кость добавляется из руки
(часто после взятия со стены). В момент повышения панга до конга
другие могут [ограбить конг](rules-winning), если эта кость
завершает их выигрыш.

## После объявления

- Конг зафиксирован; переставлять нельзя.
- Берут **добавочную**, затем сброс (или выигрыш на добавочной).
- Конг считается сетом в [стандартной руке](rules-hands) и для
  [комбинаций конгов (4.3)](pattern-4.3).
