# Панг (тройка)

Три **одинаковые** кости (один рисунок).

:::center
{333p} · {EEE} · {CCC}
:::

[Ветры](rules-winds) и [драконы](rules-dragons) образуют тройки
(или конги) только из **одного и того же** рисунка — не «сет из всех
ветров» и не «сет из всех драконов». По одной кости каждого ветра
({E}{S}{W}{N}) или каждого дракона ({P}{F}{C}) — это просто разные
кости, а не сет. Нужны три Востока для тройки Востока, три Красных
для тройки красного дракона и так далее.

(Комбинации вроде [Больших четырёх ветров (3.3.4)](pattern-3.3.4) всё
равно требуют настоящих **троек** ветров — одной кости каждого
недостаточно.)

Третью кость можно взять **с любого** сброса — **панг**. См.
[Объявления](rules-claims).

Четыре одинаковые кости, объявленные как сет, — это
[конг](rules-kong-types), а не «длинная тройка».
