# Стена и последние кости

Кости берут со **стены**. В стандартном Чжун-юн часть стены —
**мёртвая** — не разыгрывается обычными ходами.

## Мёртвая стена

Последние **14** костей стены — **мёртвая стена**; обычными ходами
их не берут. Добавочные после конга берут из принятого для этого
участка стены; для новичка важно: обычные взятия заканчиваются
до этих зарезервированных костей.

В этом приложении мёртвая стена **не показывается** на столе —
рисуется только живая стена.

## Морское дно (последняя кость стены)

**Морское дно** — **последняя живая** кость стены, которую ещё
можно взять обычным (или добавочным) взятием. Взятие со стены
этой кости — [Последняя кость стены (9.1.1)](pattern-9.1.1).

Если это добавочная после конга на морском дне,
[Выигрыш на замене конга (9.2)](pattern-9.2) может сложиться с
последней костью стены.

## Последний сброс (дно реки)

После взятия морского дна **сброс** этого игрока (если никто ещё
не выиграл) — **последний сброс**. Выигрыш на нём —
[Последний сброс (9.1.2)](pattern-9.1.2).

## Ничья (нет выигрыша)

Если живая стена исчерпана без выигрыша — обычно после сброса
взявшего морское дно, если последний сброс никто не забрал, —
партия **вничью** (нет победителя). Выигрывающую руку никто не
считает.
