# Пара (глаза)

Две **одинаковые** кости, завершающие стандартную руку.

:::center
{55s} · {WW}
:::

Пара — **не** сет. В [стандартной руке](rules-hands) нужна ровно одна
пара (кроме [нестандартных](rules-hands) форм вроде
[семи пар](pattern-10.2)).

Пара может быть из любой кости — номеров, [ветров](rules-winds) или
[драконов](rules-dragons).
Некоторые комбинации учитывают, какая именно пара (например, пара из
благородных блокирует [Все простые (1.3)](pattern-1.3)), но самой
форме руки нужна просто одна пара.
