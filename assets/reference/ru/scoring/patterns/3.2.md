# Драконы

**3.2** · 三元

Комбинации драконов: два сета драконов плюс пара-глаза (малые)
или три панга/конга драконов (большие). Всегда также считайте
[Ценные благородные (3.1)](pattern-3.1).

## Комбинации

- [**3.2.1** Малые три дракона](pattern-3.2.1) — [hl]**40**[/] (всегда +2×[3.1](pattern-3.1) → ≥60)
- [**3.2.2** Большие три дракона](pattern-3.2.2) — [hl]**130**[/] (всегда +3×[3.1](pattern-3.1) → ≥160)

[muted]Серия 3.2 — только один (высший подходящий).[/]
