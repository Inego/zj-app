# Малые / Большие

**8.1** · 全帶/么九

Малые терминалы (чоу с краями 1/9 допустимы) против больших
(только терминалы и благородные). Считается высший подходящий.

## Комбинации

- [**8.1.1** Смешанные малые терминалы](pattern-8.1.1) — [hl]**40**[/]
- [**8.1.2** Чистые малые терминалы](pattern-8.1.2) — [hl]**50**[/]
- [**8.1.3** Смешанные большие терминалы](pattern-8.1.3) — [hl]**100**[/]
- [**8.1.4** Чистые большие терминалы](pattern-8.1.4) — [hl]**400**[/] (табличный лимит)

[muted]Серия 8.1 — только один (высший подходящий).[/]
