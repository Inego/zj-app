# Четыре закрытых панга

**4.2.3** · 四暗刻 · [hl]**125 очков**[/]

Четыре закрытых панга или закрытых конга. Подразумеваемые
комбинации других серий всё равно считаются (например,
[Закрытая рука](pattern-1.2) + [Все панги](pattern-4.1) → минимум 160).

[muted]Серия 4.2 — высшая ступень закрытых пангов.[/]
