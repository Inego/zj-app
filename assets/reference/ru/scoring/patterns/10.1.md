# Тринадцать сирот

**10.1** · 十三么九 · [hl]**160 очков**[/]

Среди 13 терминальных и благородных типов: одна пара плюс по
одной каждой из остальных двенадцати. **Не** считает
[Закрытую руку (1.2)](pattern-1.2).

Без особых привилегий: нельзя ограбить [закрытый конг](rules-kong-types);
можно [перехватить](rules-winning) как обычный выигрыш.
