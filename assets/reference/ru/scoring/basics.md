# Основы подсчёта

Чжун-юн — **комбинационная** аддитивная система (v3.3). Очки
считаются только у выигравшей руки. Базового пола (副底) нет:
стоимость руки — сумма очков комбинаций.

## Правило сложения

- Считайте комбинации из **разных серий**.
- Внутри одной серии — **только один** (обычно высший
  подходящий).
- **Исключение — [Ценные благородные (3.1)](pattern-3.1):** +10 **за каждый**
  подходящий сет; суммируется с другими комбинациями благородных.

Серии совпадают по первым двум уровням ID (например, все [4.2.x](pattern-4.2) —
одна серия). На страницах комбинаций есть пометки о серии.

## Рука без комбинаций

Полная [стандартная рука](rules-hands) **без** очковых комбинаций
стоит [hl]**1**[/] очко — см. [Рука без комбинаций](scoring-chicken-hand).
В стандартном Чжун-юн минимума нет (вариант с минимумом 5 очков —
отдельное правило).

## Лимиты

- **Составной лимит:** если сумма комбинаций ≥ 320, рука даёт
  [hl]**320**[/] (комбинации при этом «есть» концептуально).
- **Табличный лимит:** одна комбинация на 320+ даёт **только**
  её очки (остальное не добавляется). При нескольких таких
  выбирается наибольшая.

## Выплаты (формально)

Победитель всегда получает **3 × стоимость руки**.

- **[Со стены](rules-winning):** каждый из троих платит полную стоимость.
- **[На сбросе](rules-winning), стоимость ≤ 25:** каждый из троих платит полную
  стоимость.
- **На сбросе, стоимость > 25:** каждый невиновный платит
  **25**; сбросивший платит **3×стоимость − 50**.

[Превалирующего ветра](rules-seats) нет. [Ветер места](rules-seats) и
[драконы](rules-dragons) — ценные благородные для [3.1](pattern-3.1).
