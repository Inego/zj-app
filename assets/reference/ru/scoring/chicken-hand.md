# Рука без комбинаций

雞和 · [hl]**1 очко**[/]

Полная [стандартная рука](rules-hands) (четыре сета + пара), которая
**не** подходит ни под одну комбинацию категорий 1–9. В стандартном
Чжун-юн **минимума нет**: такой выигрыш без комбинаций законен и даёт
символическое [hl]**1**[/] очко.

:::center
{567s}{333m}{456m}{234s}{FF}
:::

В этой форме есть [панг](rules-triplet) (не [Все последовательности](pattern-1.1)),
благородные в паре (не [Все простые](pattern-1.3)), и — если сет
забирали со сброса — рука открыта (не [Закрытая рука](pattern-1.2)).
Без других комбинаций это рука без комбинаций.

## Домашнее правило в приложении

В настройках партии есть **Разрешить руки без комбинаций** (по умолчанию
выкл.). Если выключено, чистая рука без комбинаций не может объявить Ху
(считается ложным выигрышем). Если включено — даёт [hl]**1**[/],
как выше.

## Вариант (официальный)

Некоторые турниры вводят **минимум 5 очков**; тогда руки без комбинаций
запрещены. Это опция события, не стандартные правила по умолчанию.

[muted]Рука без комбинаций — не нумерованная серия комбинаций, а остаточный
счёт, когда законная стандартная рука не набрала очков по
комбинациям.[/]
