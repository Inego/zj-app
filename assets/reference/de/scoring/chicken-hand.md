# Musterlose Hand

雞和 · [hl]**1 Punkt**[/]

Eine vollständige [reguläre Hand](rules-hands) (vier Gruppen + Augen), die
**keinem** der Wertungsmuster der Kategorien 1–9 entspricht. Standard-Zung-Jung
hat **kein Minimum**: Dieser musterlose Sieg ist weiterhin legal und erzielt einen
symbolischen [hl]**1**[/] Punkt.

:::center
{567s}{333m}{456m}{234s}{FF}
:::

Diese Form hat einen [Drilling](rules-triplet) (nicht [Nur Folgen](pattern-1.1)),
Ehren-Augen (nicht [Keine Endsteine](pattern-1.3)) und ist — wenn eine Gruppe
beansprucht wurde — offen (nicht [Verdeckte Hand](pattern-1.2)). Ohne weitere
Muster ist sie eine musterloose Hand.

## Hausregel in dieser App

Die Spiel-Einrichtung enthält **Musterlose Hände erlauben** (standardmäßig aus). Wenn aus,
kann eine reine musterloose Hand kein Hu erklären (sie gilt als falscher Sieg).
Wenn an, erzielt sie wie oben [hl]**1**[/].

## Variante (offiziell)

Manche Turniere verwenden ein **5-Punkte-Minimum**; musterloose Hände sind dann
illegal. Das ist eine Haus-/Veranstaltungsoption, nicht die Standardregel.

[muted]Die musterloose Hand ist keine nummerierte Musterreihe — sie ist der Restwert,
wenn eine legale reguläre Hand null Musterpunkte hat.[/]
