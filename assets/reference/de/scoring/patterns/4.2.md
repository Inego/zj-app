# Verdeckte Drillinge

**4.2** · 暗刻

Wie viele Drillinge/Kongs vollständig **verdeckt** waren (alle Steine von der Mauer, einschließlich eines Selbstziehungs-Gewinnsteins). Ein Sieg auf einem Abwurf vervollständigt einen **aufgedeckten** Drilling.
