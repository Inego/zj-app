# Verdeckte Hand

**1.2** · 門前清 · [hl]**5 Punkte**[/]

[Reguläre Hand](rules-hands) mit **keinen [aufgedeckten Meldungen](rules-concealed-open)**
vor dem Sieg. Ein Sieg auf einem Abwurf ist erlaubt. Ein
**[verdeckter Kong](rules-kong-types)** bricht dieses Muster nicht; ein
offener Kong schon.

Irreguläre Hände ([Kategorie 10](pattern-10)) zählen **nicht** als Verdeckte Hand.

[muted]Reihe 1.2 — eigene Reihe.[/]
