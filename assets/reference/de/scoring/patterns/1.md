# Einfach

**1** · 門斷平

Muster mit wenigen Punkten, die bei gewöhnlichen Händen häufig sind: nur Folgen, eine vollständig verdeckte reguläre Hand oder nur mittlere Zahlen (2–8).

## Muster

- [**1.1** Nur Folgen](pattern-1.1) — [hl]**5**[/]
- [**1.2** Verdeckte Hand](pattern-1.2) — [hl]**5**[/]
- [**1.3** Keine Endsteine](pattern-1.3) — [hl]**5**[/]

[muted]Jedes von [1.1](pattern-1.1), [1.2](pattern-1.2) und [1.3](pattern-1.3) ist eine eigene Reihe (sie können sich kombinieren).[/]
