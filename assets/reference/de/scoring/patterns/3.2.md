# Drachen

**3.2** · 三元

Drachenkombinationen: zwei Drachen-Gruppen plus Drachen-Augen (klein) oder drei Drachen-Drillinge/Kongs (groß). Zähle immer auch [Wertvolle Ehre (3.1)](pattern-3.1).

## Muster

- [**3.2.1** Kleine drei Drachen](pattern-3.2.1) — [hl]**40**[/] (immer +2×[3.1](pattern-3.1) → ≥60)
- [**3.2.2** Große drei Drachen](pattern-3.2.2) — [hl]**130**[/] (immer +3×[3.1](pattern-3.1) → ≥160)

[muted]Reihe 3.2 — zähle nur eines (das höchste, das zutrifft).[/]
