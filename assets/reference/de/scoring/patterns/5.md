# Identische Gruppen

**5** · 一色同順

Identische Folgen — gleiche [Farbe](rules-suits) und gleiche Zahlen — von einem einzelnen Chow-Paar bis zu vier identischen Folgen.

## Muster

- [**5.1** Identische Folgen](pattern-5.1) (Reihe)
- [**5.1.1** Zwei identische Folgen](pattern-5.1.1) — [hl]**10**[/]
- [**5.1.2** Zwei identische Folgen zweimal](pattern-5.1.2) — [hl]**60**[/]
- [**5.1.3** Drei identische Folgen](pattern-5.1.3) — [hl]**120**[/]
- [**5.1.4** Vier identische Folgen](pattern-5.1.4) — [hl]**480**[/] (aufgelistetes Limit)

[muted]Reihe [5.1](pattern-5.1) — zähle nur die höchste Stufe, die zutrifft.[/]
