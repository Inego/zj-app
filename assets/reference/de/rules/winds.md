# Winde

Vier **[Ehren](rules-honors)**-Motive — keine nummerierte [Farbe](rules-suits):

:::center
{E}{S}{W}{N}
:::

- **Ost** (東)
- **Süd** (南)
- **West** (西)
- **Nord** (北)

Winde haben keine Rangordnung. Sie können keine [Folgen](rules-sequence) bilden —
nur [Drillinge](rules-triplet) oder [Kongs](rules-kong-types) des
**gleichen** Motivs (drei Oste, nicht „je einer jedes Windes“).

## Sitzwind vs. Stein

Jeder Spieler hat einen **[Sitzwind](rules-seats)**, der zu seinem Sitz passt. Ein
Drilling oder Kong **deines** Sitzwindes bringt
[Wertvolle Ehre (3.1)](pattern-3.1). Die Sitzwinde anderer Spieler bringen
dir keine Wertvolle Ehre.

Zung Jung hat **keinen** vorherrschenden (Runden-/Tisch-)Wind.

## Wertungsmuster

Wind-**Gruppen**-Kombinationen (drei oder vier verschiedene Wind-Drillinge/Kongs):
[Winde (3.3)](pattern-3.3).
