# Beanspruchungen

Beim **frischen Abwurf** eines anderen Spielers (nicht einem älteren Stein im Fluss)
kannst du ihn **beanspruchen**, wenn er eine Gruppe oder einen Sieg vervollständigt.

## Chow

- Vervollständige eine [Folge](rules-sequence) mit dem abgeworfenen Stein.
- Nur vom **oberen Sitz** (dem Spieler, der direkt vor dir abwirft —
  in Standard-Sitzdiagrammen zu deiner Linken).
- Nach einem Chow: Meldung aufdecken, dann abwerfen; das Spiel geht von dir weiter.

## Pung

- Vervollständige einen [Drilling](rules-triplet) mit dem abgeworfenen Stein.
- Von **jedem** Spieler.
- Nach einem Pung: Meldung aufdecken, dann abwerfen; das Spiel geht von dir weiter
  (dazwischenliegende Spieler werden übersprungen).

## Kong (aus Abwurf)

- **Großer offener Kong:** halte einen verdeckten Drilling; beanspruche den vierten aus
  einem Abwurf. Siehe [Kong](rules-kong-types).

## Sieg

- Beanspruche den Abwurf, um eine legale Gewinnform zu vervollständigen
  ([Wie du gewinnst](rules-winning)).
- Höchste Priorität über Gruppen-Beanspruchungen.

## Beanspruchungs-Priorität

Wenn mehrere Spieler denselben Abwurf wollen:

1. **Sieg** (höchste)
2. **Pung** oder **großer offener Kong**
3. **Chow** (niedrigste)

Wenn mehrere Spieler einen **Sieg** beanspruchen, löst die
[Abfangung](rules-winning) auf, wer ihn bekommt (Sitzreihenfolge relativ zum Abwerfenden). Standard-
Zung Jung verwendet klassische Einzelsieger-Abfangung, nicht Mehrfachsieg auf
einem Abwurf.
