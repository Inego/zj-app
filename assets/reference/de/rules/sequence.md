# Folge

Eine Folge sind **genau drei** aufeinanderfolgende Zahlen der
**gleichen [Farbe](rules-suits)**. Ehren können keine Folgen bilden.

:::center
{123m} · {567p} · {789s}
:::

Eine längere Reihe ist **keine** „bessere Folge“. Zum Beispiel ist {3456m} vier
Steine, keine einzelne Gruppe: Du musst sie trotzdem als **zwei** Teile der
Hand gruppieren (etwa eine Folge {345m} mit einem übrigen {6m}, oder {456m} mit einem
übrigen {3m}). Diese vier Steine zählen nie als eine einzelne Vier-Steine-Folge.

Nur **3** in einer Reihe sind eine Gruppe. Nur **3** gleiche Steine sind ein
[Drilling](rules-triplet) (und nur **4** gleiche sind ein
[Kong](rules-kong-types) — eine andere Art von Gruppe, keine längere
Folge).

Eine Folge aus einem Abwurf zu beanspruchen ist ein **Chow** (nur vom Spieler
zu deiner Linken — dem oberen Sitz). Siehe [Beanspruchungen](rules-claims).
