# Gruppen & Augen

Eine **reguläre Hand** besteht aus **Gruppen** plus **Augen** (einem Paar). Siehe
[Reguläre & irreguläre Hände](rules-hands).

Jede Gruppe ist eine von:

- **[Folge](rules-sequence)** — drei aufeinanderfolgende Zahlen, gleiche [Farbe](rules-suits)
- **[Drilling](rules-triplet)** — drei gleiche Steine
- **[Kong](rules-kong-types)** — vier gleiche Steine, erklärt

Dazu das abschließende Paar:

- **[Augen](rules-eyes)** — zwei gleiche Steine (keine Gruppe)

:::center
{123m} · {333p} · {1111s} · {55p}
:::

Kongs zählen nach der Erklärung als Gruppen und erfordern eine
[Ersatzziehung](rules-kong-types). Das Beanspruchen von Gruppen aus Abwürfen ist
unter [Beanspruchungen](rules-claims) behandelt.
