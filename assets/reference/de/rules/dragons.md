# Drachen

Drei **[Ehren](rules-honors)**-Motive — keine nummerierte [Farbe](rules-suits):

:::center
{P}{F}{C}
:::

- **Weiß** (白) — {P}
- **Grün** (發) — {F}
- **Rot** (中) — {C}

Drachen haben keine Rangordnung. Sie können keine [Folgen](rules-sequence) bilden
— nur [Drillinge](rules-triplet) oder [Kongs](rules-kong-types) des
**gleichen** Motivs (drei Rote, nicht „je einer jedes Drachen“).

Jeder Drachen-Drilling oder -Kong ist für jeden Spieler immer eine
[Wertvolle Ehre (3.1)](pattern-3.1) (+10 pro Gruppe).

## Wertungsmuster

Drachen-Kombinationen: [Drachen (3.2)](pattern-3.2)
([Kleine](pattern-3.2.1) / [Große drei Drachen](pattern-3.2.2)).
