# Eine Hand gewinnen

Du gewinnst, indem du eine legale [Handform](rules-hands) vervollständigst und
den Sieg erklärst. Wie der letzte Stein ankommt, beeinflusst sowohl das Verfahren als auch einige
[zufällige Muster (9)](pattern-9).

## Rufbereit (wartende Hand)

Eine Hand ist **rufbereit** (wartend), wenn sie **einen Stein** von einem legalen
Sieg entfernt ist — jede von mehreren Steinarten kann sie vervollständigen (eine mehrseitige Wartestellung).

Beispiel: [Neun Tore (2.2)](pattern-2.2) ist eine berühmte neunfache Wartestellung auf
eine [Farbe](rules-suits).

## Selbstziehung

Du ziehst den abschließenden Stein selbst von der Mauer. Kein Abwerfender.
Auszahlung: Jeder der anderen drei zahlt den vollen Handwert — siehe
[Wertungsgrundlagen](scoring-basics).

## Sieg auf Abwurf

Du beanspruchst den Abwurf eines anderen Spielers als abschließenden Stein. Dieser Spieler
ist der **Abwerfende** (oft der „verantwortliche“ Zahler bei großen Händen).
Die durch diesen Stein vervollständigte Gruppe ist [aufgedeckt](rules-concealed-open).

## Kong ausrauben

Wenn jemand einen **kleinen offenen Kong** erklärt, kannst du, wenn dieser hinzugefügte Stein
deine Hand gewinnt, ihn für den Sieg beanspruchen
([Kong ausrauben (9.3)](pattern-9.3)). Wird für die Auszahlung als **Sieg auf Abwurf**
behandelt. Du kannst keinen **verdeckten** Kong ausrauben (auch nicht mit
Dreizehn Endsteinen).

## Abfangung

Wenn mehr als ein Spieler einen Sieg auf demselben Abwurf beansprucht, wird **ein** Sieger
nach Sitzreihenfolge vom Abwerfenden aus gewählt: **unterer Sitz** (als Nächster in der
Zugreihenfolge) schlägt Gegenüber, der den oberen Sitz schlägt. Standard-Zung-Jung vergibt keinen
Mehrfachsieg auf einem Abwurf.
