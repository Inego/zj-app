# Επτά ζεύγη

**10.2** · 七對子 · [hl]**30 πόντοι**[/]

Επτά ζεύγη. Τέσσερα πανομοιότυπα πλακίδια υπολογίζονται ως **δύο ζεύγη** εάν δεν
έχει δηλωθεί κονγκ. **Δεν** υπολογίζει το [Κρυφό χέρι (1.2)](pattern-1.2).

Δεν μπορεί να υπολογίσει συνδυασμούς που απαιτούν τριάδες, κονγκ ή
σειρές. Άλλοι συνδυασμοί εξακολουθούν να ισχύουν (π.χ. [μίας φυλής](pattern-2),
[άκρων](pattern-8), [τιμών](pattern-3)).
