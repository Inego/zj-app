# Τιμή αξίας

**3.1** · 番牌 · [hl]**10 πόντοι / σετ**[/]

Τριάδα ή κονγκ του **[ανέμου θέσης σας](rules-seats)** ή οποιουδήποτε
**[δράκου](rules-dragons)**. Μετράει **σωρευτικά ανά σετ** (+10 έκαστο).
**Δεν** υπάρχει [κυρίαρχος άνεμος](rules-seats) στο Zung Jung. Πλακίδια
**ανέμων:** [Άνεμοι](rules-winds).

[Μεγάλους τρεις δράκους](pattern-3.2.2) και τους [συνδυασμούς ανέμων](pattern-3.3)
όταν ισχύουν επίσης (π.χ. οι [Μεγάλοι τρεις δράκοι](pattern-3.2.2)
περιλαμβάνουν πάντα 3× Τιμή αξίας → τουλάχιστον 160).
