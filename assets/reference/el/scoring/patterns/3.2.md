# Δράκοι

**3.2** · 三元

Συνδυασμοί δράκων: δύο σετ δράκων συν μάτια δράκου (μικροί) ή τρεις τριάδες/κονγκ δράκων (μεγάλοι). Μετράει πάντα επιπλέον η [Τιμή αξίας (3.1)](pattern-3.1).

## Συνδυασμοί

- [**3.2.1** Μικροί τρεις δράκοι](pattern-3.2.1) — [hl]**40**[/] (πάντα +2×[3.1](pattern-3.1) → ≥60)
- [**3.2.2** Μεγάλοι τρεις δράκοι](pattern-3.2.2) — [hl]**130**[/] (πάντα +3×[3.1](pattern-3.1) → ≥160)

[muted]Σειρά 3.2 — υπολογίζεται μόνο ένας (ο υψηλότερος που ταιριάζει).[/]
