# Μικρά / Μεγάλα

**8.1** · 帶么／么九

Μικρά άκρα (σειρές με ακραία 1/9 δεκτές) έναντι μεγάλων (μόνο άκρα και τιμές). Υπολογίζεται ο υψηλότερος που ταιριάζει.

- [**8.1.1** Μικτά μικρά άκρα](pattern-8.1.1) — [hl]**40**[/]
- [**8.1.2** Καθαρά μικρά άκρα](pattern-8.1.2) — [hl]**50**[/]
- [**8.1.3** Μικτά μεγάλα άκρα](pattern-8.1.3) — [hl]**100**[/]
- [**8.1.4** Καθαρά μεγάλα άκρα](pattern-8.1.4) — [hl]**400**[/] (ονομαστικό όριο)
