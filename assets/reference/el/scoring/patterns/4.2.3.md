# Τέσσερις κρυφές τριάδες

**4.2.3** · 四暗刻 · [hl]**125 πόντοι**[/]

Τέσσερις κρυφές τριάδες ή κρυφά κονγκ. Έμμεσοι συνδυασμοί σε
άλλες σειρές εξακολουθούν να μετρούν (π.χ. [Κρυφό χέρι](pattern-1.2) +
[Όλα τριάδες](pattern-4.1) → τουλάχιστον 160).
