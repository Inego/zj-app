# Δράκοι

Τρία σχέδια **[τιμών](rules-honors)** — δεν ανήκουν σε αριθμημένη [φυλή](rules-suits):

:::center
{P}{F}{C}
:::

- **Λευκός** (白) — {P}
- **Πράσινος** (發) — {F}
- **Κόκκινος** (中) — {C}

Οι δράκοι δεν έχουν σειρά κατάταξης. Δεν μπορούν να σχηματίσουν [σειρές](rules-sequence)
— μόνο [τριάδες](rules-triplet) ή [κονγκ](rules-kong-types) του
**ίδιου** σχεδίου (τρεις Κόκκινοι, όχι «ένας από κάθε δράκο»).

Οποιαδήποτε τριάδα ή κονγκ δράκων αποτελεί πάντοτε
[Τιμή αξίας (3.1)](pattern-3.1) (+10 ανά σετ), για κάθε παίκτη.
