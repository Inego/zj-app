# Κανονικά και ακανόνιστα χέρια

Για να κερδίσετε, το χέρι πρέπει να ταιριάζει με ένα νόμιμο **νικητήριο σχήμα**. Οι συνδυασμοί βαθμολογίας
στις κατηγορίες 1–9 **δεν** δημιουργούν εναλλακτικά σχήματα — απλώς αποτιμούν ένα
χέρι που είναι ήδη ολοκληρωμένο.

## Κανονικό χέρι

**Τέσσερα σετ** + **ένα ζεύγος** (μάτια).

Κάθε σετ είναι μια [σειρά](rules-sequence), [τριάδα](rules-triplet) ή
[κονγκ](rules-kong-types). Τα κονγκ μετρούν ως σετ μόλις δηλωθούν. Το
ζεύγος ολοκλήρωσης ([μάτια](rules-eyes)) βρίσκεται εκτός των τεσσάρων σετ.

Παράδειγμα σχήματος (σχηματικά): τέσσερις ομάδες + ένα ζεύγος → 14 πλακίδια όταν ολοκληρωθεί
(με κονγκ, οι δηλωμένες τετράδες και ένα συμπλήρωμα διατηρούν το χέρι νόμιμο).

### Χέρι χωρίς συνδυασμούς

Ένα πλήρες κανονικό χέρι **χωρίς** συνδυασμούς βαθμολογίας εξακολουθεί να είναι νόμιμη
νίκη στο κανονικό Zung Jung — το [χέρι χωρίς συνδυασμούς](scoring-chicken-hand)
βαθμολογείται με [hl]**1**[/] πόντο.

Ορισμένοι παίκτες και τουρνουά απαγορεύουν τα χέρια χωρίς συνδυασμούς (μετρούν ως
ψευδής νίκη). Αυτή η επιλογή υποστηρίζεται σε αυτήν την εφαρμογή στις ρυθμίσεις του παιχνιδιού
(**Να επιτρέπονται χέρια χωρίς συνδυασμούς**).

## Ακανόνιστα χέρια (Zung Jung)

Μόνο τα σχήματα που αναφέρονται στα [Ακανόνιστα χέρια (10)](pattern-10) μπορούν να κερδίσουν
χωρίς τη μορφή των τεσσάρων σετ:

- [Δεκατρία άκρα (10.1)](pattern-10.1)
- [Επτά ζεύγη (10.2)](pattern-10.2)

Παραδείγματα που εξακολουθούν να απαιτούν κανονικό σχήμα (ή Επτά ζεύγη):

- [Όλα τιμές (3.4)](pattern-3.4) — όλα τα πλακίδια είναι τιμές, αλλά εξακολουθούν να απαιτούν τέσσερα σετ
  + μάτια **ή** Επτά ζεύγη
- [Όλα τριάδες (4.1)](pattern-4.1) — τέσσερις τριάδες/κονγκ + μάτια
