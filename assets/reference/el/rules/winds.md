# Άνεμοι

Τέσσερα σχέδια **[τιμών](rules-honors)** — δεν ανήκουν σε αριθμημένη [φυλή](rules-suits):

:::center
{E}{S}{W}{N}
:::

- **Ανατολή** (東)
- **Νότος** (南)
- **Δύση** (西)
- **Βορράς** (北)

Οι άνεμοι δεν έχουν σειρά κατάταξης. Δεν μπορούν να σχηματίσουν [σειρές](rules-sequence) —
μόνο [τριάδες](rules-triplet) ή [κονγκ](rules-kong-types) του **ίδιου**
σχεδίου (τρεις Ανατολές, όχι «ένας από κάθε άνεμο»).

## Άνεμος θέσης έναντι πλακιδίου

Κάθε παίκτης έχει έναν **[άνεμο θέσης](rules-seats)** που αντιστοιχεί στη θέση του. Μια
τριάδα ή κονγκ του ανέμου της **δικής σας** θέσης δίνει
[Τιμή αξίας (3.1)](pattern-3.1). Οι άνεμοι θέσης των άλλων παικτών δεν δίνουν
Τιμή αξίας για εσάς.

Το Zung Jung **δεν** έχει κυρίαρχο άνεμο (γύρου ή τραπεζιού).
