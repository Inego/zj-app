# Τιμές (Honors)

Οι **τιμές** είναι τα επτά σχέδια χωρίς φυλή: τέσσερις **[άνεμοι](rules-winds)**
και τρεις **[δράκοι](rules-dragons)**. Δεν αποτελούν μέρος αριθμημένης
[φυλής](rules-suits) και **δεν έχουν αριθμητική σειρά** για σειρές.

:::center
{E}{S}{W}{N} · {P}{F}{C}
:::

## Τι μπορούν να σχηματίσουν οι τιμές

- [Τριάδες](rules-triplet) και [κονγκ](rules-kong-types) του **ίδιου**
  σχεδίου (τρεις Ανατολές, τρεις Κόκκινοι δράκοι, …)
- [Μάτια](rules-eyes) (ένα ζεύγος του ίδιου σχεδίου)

**Δεν** μπορούν να σχηματίσουν [σειρές](rules-sequence). Ένας από κάθε άνεμο ή ένας
από κάθε δράκο δεν αποτελεί σετ.

## Οικογένειες

- **[Άνεμοι](rules-winds)** — Ανατολή, Νότος, Δύση, Βορράς
- **[Δράκοι](rules-dragons)** — Λευκός, Πράσινος, Κόκκινος
