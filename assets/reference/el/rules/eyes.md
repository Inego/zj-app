# Μάτια (ζεύγος)

Δύο **πανομοιότυπα** πλακίδια που συμπληρώνουν ένα κανονικό χέρι (το «ζεύγος» /
«μάτια»).

:::center
{55s} · {WW}
:::

Τα μάτια **δεν** είναι σετ. Χρειάζεστε ακριβώς ένα ζεύγος σε ένα
[κανονικό χέρι](rules-hands) (εκτός αν κερδίσετε με ακανόνιστο σχήμα
όπως τα [Επτά ζεύγη](pattern-10.2)).

Τα μάτια μπορούν να είναι οποιουδήποτε σχεδίου — αριθμητικά, [άνεμοι](rules-winds) ή
[δράκοι](rules-dragons). Οι συνδυασμοί βαθμολογίας
μερικές φορές ενδιαφέρονται για το ποια είναι τα μάτια (για παράδειγμα, μάτια τιμών αποκλείουν
το [Χωρίς άκρα (1.3)](pattern-1.3)), αλλά το ίδιο το σχήμα του χεριού χρειάζεται
μόνο ένα ζεύγος.
