# Σειρά

Μια σειρά αποτελείται από **ακριβώς τρεις** διαδοχικούς αριθμούς στην
**ίδια [φυλή](rules-suits)**. Οι τιμές δεν μπορούν να σχηματίσουν σειρές.

:::center
{123m} · {567p} · {789s}
:::

Μια μακρύτερη σειρά **δεν** αποτελεί «καλύτερη σειρά». Για παράδειγμα, το {3456m} είναι τέσσερα
πλακίδια, όχι ένα σετ: πρέπει να τα ομαδοποιήσετε ως **δύο** τμήματα του
χεριού (για παράδειγμα μια σειρά {345m} με ένα επιπλέον {6m}, ή {456m} με ένα
επιπλέον {3m}). Αυτά τα τέσσερα πλακίδια δεν μετρούν ποτέ ως μία ενιαία σειρά τεσσάρων πλακιδίων.

Μόνο **3** στη σειρά αποτελούν σετ. Μόνο **3** πανομοιότυπα πλακίδια αποτελούν
[τριάδα](rules-triplet) (και μόνο **4** πανομοιότυπα αποτελούν
[κονγκ](rules-kong-types) — ένα διαφορετικό είδος σετ, όχι μεγαλύτερη
σειρά).

Η διεκδίκηση σειράς από απόρριψη ονομάζεται **τσόου** (μόνο από τον παίκτη
στα αριστερά σας — την ανώτερη θέση). Δείτε [Δηλώσεις](rules-claims).
