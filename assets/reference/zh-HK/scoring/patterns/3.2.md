# 三元牌系列

**3.2** · 三元牌系列

三元牌的組合：兩個三元牌刻／槓加上一對三元牌做眼（小三元），或三個三元牌刻／槓（大三元）。必同時加算[番牌 (3.1)](pattern-3.1)。

## 和種

- [**3.2.1** 小三元](pattern-3.2.1) — [hl]**40**[/]（必加計 2×[3.1](pattern-3.1) → 起碼 60 分）
- [**3.2.2** 大三元](pattern-3.2.2) — [hl]**130**[/]（必加計 3×[3.1](pattern-3.1) → 起碼 160 分）

[muted]系列 3.2 — 只計其中一個（最高分者）。[/]
