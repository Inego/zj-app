# 番牌

**3.1** · 番牌 · [hl]**10 分／組**[/]

[門風（自風）](rules-seats)或任何[三元牌](rules-dragons)的[刻子](rules-triplet)／[槓子](rules-kong-types)。按**每組刻／槓獨立加算**（每刻+10分）。
注意：「中庸」**不計**場風（圈風）。[風牌](rules-winds)。

與[小三元](pattern-3.2.1)／[大三元](pattern-3.2.2)及[風牌和種](pattern-3.3)複合時一律加算（例如[大三元](pattern-3.2.2)必包含三組番牌刻子 → 起碼 160 分）。
