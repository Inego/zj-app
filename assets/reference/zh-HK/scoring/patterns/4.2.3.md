# 四暗刻

**4.2.3** · 四暗刻 · [hl]**125 分**[/]

手牌有四個[暗刻](rules-triplet)／[暗槓](rules-kong-types)。俗稱「刻刻和」。
銃和單騎聽牌算四暗刻；雙碰聽牌銃和時，和出的那一刻作明刻計（為[三暗刻 (4.2.2)](pattern-4.2.2)）。自摸和雙碰則算四暗刻。
必定加算[門前清 (1.2)](pattern-1.2)及[對對和 (4.1)](pattern-4.1)，故起碼得 125+5+30=160 分。

摸入：{111m}{555m}{333p}{888s}{EE}
:::
