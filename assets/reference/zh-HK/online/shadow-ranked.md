# 影子段位

**影子段位**是一種特殊段位賽制的名稱，由四項元素組合而成：

1. **複式賽制** — 你每局影子段位對局都是一個特定的**複式局**，其他玩家已在你之前玩過（及／或會在你之後玩）：起手牌、牌牆與座位保證完全相同，把運氣因素減至最低。你的成績並非你相對於同桌另外三家的得分，而是你的總分相對於所有以相同牌張、在相同座位玩過同一複式局的其他玩家之總分。
2. **與三位電腦對局** — 每局影子段位對局中，你都會與三位電腦對戰（即即時段位對局中用作補位的相同電腦）。這樣便無須其他玩家在線。
3. **異步比較** — 玩家無須同時在線，每個成績都會與其他成績比較，並推動雙方玩家的積分。
4. **動態複式局池** — 伺服器在有開放中的複式局時會重複使用，只有在沒有時才建立新的。每個複式局都會開放給其他玩家，並在容納滿 **10 位真人玩家**或經過 **30 天**後退役。

## 為何存在

即時段位對局需要數人同時在線，而這很少發生。比較同桌玩家的得分還有另一個問題：麻雀一半靠技術、一半靠運氣，而每個座位獲配的牌都不同，因此比較玩家的總分，既反映了配牌，也反映了打法。增加局數可減少運氣的影響，卻無法完全消除。影子段位同時解決兩者：玩同一個複式局幾乎可將運氣從比較中剔除，而你也無須等待其他玩家。

## 對局如何進行

1. 開啟**連線對戰 → 影子段位**並登入。
2. 選擇圈數 — **1 圈**（4 局）或 **2 圈**（8 局）— 以及是否允許**雞和**。參見[雞和](scoring-chicken-hand)。
3. 按**開始一局**。伺服器會給你一個該類型、你尚未玩過的複式局，只有在沒有時才建立新的。它偏好其他玩家已經完成的複式局 — 讓你有得分可作比較 — 但你也可以成為其中第一位真人玩家。不過你永遠不會無從比較：電腦已經在你的座位玩過，因此即使你是第一位真人玩家，你的總分也會立即與它比較。

你不能選擇複式局，也無法事先得知任何關於它的事。每個複式局都有一個像 [hl]7K3H-M9PQ[/] 的識別碼，在你完成後顯示。

節奏從容：每個決定 — 自己的回合，或回應別家的捨牌 — 有 **20 秒**，另加每局**90 秒**的儲備時間。若連線中斷，重新連線即可繼續同一局對局。

## 你與誰比較

複式局事先固定：相同的牌牆、每局相同的起手牌，以及相同的電腦。每個座位各自從牌牆中屬於自己的一段摸牌。當某個座位的那段牌牆摸完後，摸牌會溢出至另一座位最長的一段牌牆，因此下一張牌取決於該局如何進行 — 牌張對所有人相同，但摸牌次序並非事先固定。每位接受此複式局的玩家都得到相同的起手牌與相同座位，因此總分的差異只來自對局如何進行。

當你完成後，你在該對局的**對局總分**會與以下比較：

- **電腦。** 建立複式局時，電腦會先在你的座位對局。其總分是你要超越的目標分數。此電腦的積分為 **1200**，且其積分永不改變。在你完成之前，你看不到它的得分。
- **每一位在你之前完成此複式局的玩家。**
- **每一位在你之後完成此複式局的玩家。** 他們的成績稍後送達，並再次推動你的積分。

每次比較都是一場勝、負，或（總分完全相同時）和局。一個複式局最多容納 **10 位真人玩家**，因此最多可提供**九位**其他玩家（加上電腦）與你比較。

## 積分

每次比較對你積分的影響，等同於在相同圈數的即時對局中對一位對手。擊敗較強的玩家可得較多；輸給較弱的玩家則損失較多。比較雙方的積分都會更新，按各玩家對局當時的積分計算。

例如積分為 1200 時，在 1 圈的複式局中擊敗積分 1200 的電腦約得 **+2.67**。在 2 圈的複式局中，同樣的勝利約得 **+5.33**。一個複式局有多位玩家即代表多次比較，每次均全額計算。

影子段位採用與即時段位對局相同的積分。

## 完成之後

成績表會顯示電腦及每一位較早的玩家：其得分、其積分，以及每次比較令你的積分變動多少。

影子段位分頁上的**我的紀錄**會顯示你玩過的每個複式局：目前有多少玩家，以及你由此獲得的總積分變動。已完成的複式局亦會顯示得分 — 電腦以及至今每一位完成它的玩家，包括在你之後才玩的玩家。

當有人稍後玩你的其中一個複式局時，成績會被保留並彙集到你下一份**摘要**：一份載有每個較後成績、各項得分及你積分變動的總結。你可在**設定**中選擇摘要的發送頻率，由**每小時**至**每日一次**（預設）。

摘要只經一個渠道發送。應用程式開啟時，摘要會在其中顯示；若應用程式已關閉而你已選擇接收電子郵件，則改以電子郵件寄出。若在待發電子郵件寄出前開啟應用程式，摘要會在應用程式內送達，並取消該電子郵件。你可在**設定**中選擇接收電子郵件。

## 公平對局

- **每個複式局僅限一次嘗試。** 一旦你開始一個複式局，即計作已玩過。即使你未完成，也不能再次取得。
- **由伺服器配牌。** 你的裝置只會接收你獲准看見的內容，因此無法從應用程式讀取隱藏的牌。
- **複式局的派發無法預測。** 在某人獲派、開始或完成一個複式局後，兩小時內不會再有其他人取得，而從開放中的複式局中選擇也帶有部分隨機性。這使得派出第二個帳號預先去探查某個複式局變得困難。
