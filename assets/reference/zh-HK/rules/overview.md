# 概述

麻雀在世界各地有多個主要規則體系 — 香港麻雀、國標麻雀（MCR）、台灣麻雀、日本麻雀（日麻）等。其中**日本日麻**在國際上特別流行。你可能已熟悉日麻，而本應用程式教授的是一套**完全不同**的規則體系。

## 中庸麻雀

**中庸麻雀**（Zung Jung）是香港**關兆豪**先生創作之**以和種為本的複合加算**麻雀計分法。其宗旨在於尋求一條適度的競技「中庸之道」，既屏棄過於單調乏味的純古典打法，又摒除過於繁瑣膨脹的現代加番流弊。本參考資料遵循 **v3.3** 版本。

中庸麻雀曾為**世界麻將大賽（World Series of Mahjong, WSoM）**的正式競賽計分體系，並獲應用於 **2008、2010 及 2015 年**的三屆世界麻將大賽中。\n
