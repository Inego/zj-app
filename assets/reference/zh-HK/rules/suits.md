# 數牌

**數牌**是指三種帶有數字的花色牌。每種花色有 **1 到 9** 各九款（每款四張），三色合共佔標準麻雀牌 34 款中的 **27 款**。

## 萬子 (萬)

文字。

:::center
{123456789m}
:::

## 筒子 (筒)

圓圈／銅錢。

:::center
{123456789p}
:::

## 索子 (索)

竹條／繩索。

:::center
{123456789s}
:::

只有數牌才能組成**[順子](rules-sequence)**（同一花色中連續的三張牌）。**[字牌](rules-honors)** — [風牌](rules-winds)與[三元牌](rules-dragons) — **非**數牌，無法組成順子；參見[麻雀牌](rules-tiles)。

計分時常關注手牌所含花色之種類：

- **單一花色** — [清一色類 (2)](pattern-2)（混一色或清一色）
- **同一花色同數字** — [一般高系列 (5)](pattern-5)
- **三色齊備同數字** — [三色類 (6)](pattern-6)
- **同一花色連續面子** — [連續類 (7)](pattern-7)\n
