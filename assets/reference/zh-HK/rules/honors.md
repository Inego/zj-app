# 字牌

**字牌**是指七款無數字花色的牌：四個**[風牌](rules-winds)**與三個**[三元牌](rules-dragons)**。它們不屬於數字[花色](rules-suits)，**無大小順序**，不可用於組成順子。

:::center
{E}{S}{W}{N} · {P}{F}{C}
:::

## 字牌能組成甚麼

- **相同**款式的三張或四張組成[刻子](rules-triplet)或[槓子](rules-kong-types)（例如三張東、三張紅中…）
- 相同款式的兩張組成[眼](rules-eyes)（對子）

字牌**不能**組成[順子](rules-sequence)。東南西北各一張或白發中各一張並非合法面子。

## 分類

- **[風牌](rules-winds)** — 東、南、西、北
- **[三元牌](rules-dragons)** — 白、發、中
