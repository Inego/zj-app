# 三元牌

三款**[字牌](rules-honors)** — 非數字[花色](rules-suits)：

:::center
{P}{F}{C}
:::

- **白**（白板） — {P}
- **發**（發財） — {F}
- **中**（紅中） — {C}

三元牌無順序。不能組成[順子](rules-sequence) — 只能由**相同**的三元牌組成[刻子](rules-triplet)或[槓子](rules-kong-types)（例如三張紅中，而非中發白各一張）。

任何三元牌的刻子或槓子，對所有玩家而言必定是 [番牌 (3.1)](pattern-3.1)（每組 +10 分）。
