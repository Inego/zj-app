# 順子

順子是指**同一[花色](rules-suits)**中數字連續的**恰好三張**牌。字牌不能組成順子。

:::center
{123m} · {567p} · {789s}
:::

四張連續牌**不是**「更長的順子」。例如 {3456m} 是四張牌，不能當作一個面子：手牌中必須將其拆成**兩個**部分（例如一組順子 {345m} 外加一張多餘的 {6m}，或順子 {456m} 外加 {3m}）。四張連續牌絕不能直接充當單一的四張順子。

只有**三張**連續牌才算一組順子。只有**三張**相同牌才是一組[刻子](rules-triplet)（四張相同牌開槓則為[槓子](rules-kong-types) — 槓子是面子的一種，而非四張的順子）。

鳴取上家打出的牌完成順子稱為**吃牌**（只能吃上家，即自己左側輪玩的玩家）。詳見[吃、碰、槓](rules-claims)。\n
