# 刻子

三張**完全相同**的牌（同花色同數字，或同字牌）。

:::center
{333p} · {EEE} · {CCC}
:::

[風牌](rules-winds)與[三元牌](rules-dragons)只能組成**同款**字牌的刻子（或槓子） — 並無「四風各一張」或「三元各一張」的面子。持有東南西北各一張（{E}{S}{W}{N}）或白發中各一張（{P}{F}{C}）只是幾張互不相干的散牌，並非面子。三張東才是東風刻子，三張紅中才是紅中刻子。

（大四喜等和種要求的是實質的風牌**刻子** — 每種各一張是無法組成的。）

鳴取他家打出的第三張牌完成刻子稱為**碰牌**。詳見[吃、碰、槓](rules-claims)。

四張相同的牌若開槓則視為[槓子](rules-kong-types)，而非四張的刻子。\n
