# 風牌

四款**[字牌](rules-honors)** — 非數字[花色](rules-suits)：

:::center
{E}{S}{W}{N}
:::

- **東** (東)
- **南** (南)
- **西** (西)
- **北** (北)

風牌無數字順序。不能組成[順子](rules-sequence) — 只能組成**相同**風牌的[刻子](rules-triplet)或[槓子](rules-kong-types)（例如三張東，而非東南西各一張）。

## 門風與風牌

每位玩家在該局中均有對應其坐位的**[門風（自風）](rules-seats)**。自己門風的刻子或槓子計為 [番牌 (3.1)](pattern-3.1)。其他三家的風牌（客風）對你而言不計番牌。

中庸麻雀**不計**場風（圈風）。
