# 面子與眼

**基本和牌形**由**四個面子**加**一對眼**（對子）組成。參見[基本與特殊和牌形](rules-hands)。

每個面子必須是以下三者之一：

- **[順子](rules-sequence)** — 同一[花色](rules-suits)數字連續的三張牌
- **[刻子](rules-triplet)** — 三張完全相同的牌
- **[槓子](rules-kong-types)** — 四張完全相同的牌（經開槓程序）

加上完成整副手牌的一對：

- **[眼（對子）](rules-eyes)** — 兩張完全相同的牌（非面子）
