# 槓子

**槓子**是由四張完全相同的牌、經過**開槓**手續組成的面子。開槓後必須從牌牆尾端摸取一張**嶺上牌（補槓）**，然後照常打出一張牌 — 除非補槓摸進的牌剛好和牌（[嶺上開花 (9.2)](pattern-9.2)）。

## 暗槓

自己手中摸齊四張相同的牌並宣告開槓。在中庸麻雀中，開暗槓者必須即時揭示四張開槓牌以資核對，防止犯規。暗槓**不影響**[門前清 (1.2)](pattern-1.2)。

暗槓**不可**被搶槓。

## 大明槓

手中有三張相同的暗刻，見他家打出第四張時鳴取該牌開槓。開槓後四張牌在檯面打開示眾成為明槓。

## 小明槓

自己已碰出了一組明刻，其後自己摸進第四張牌時開槓。開小明槓時若有他家剛好聽該張牌，他家可以[搶槓](rules-winning)和牌。

## 開槓之後

- 槓子固定在檯面上，不得改動或拆開。
- 摸取**嶺上牌（補槓）**，然後打牌（或嶺上開花和牌）。
- 槓子在[基本和牌形](rules-hands)中算作一個面子，並計入[槓子系列 (4.3)](pattern-4.3)。\n
