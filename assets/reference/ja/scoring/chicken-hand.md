# チキンハンド

チキンハンド · [hl]**1 点**[/]

[基本和了形](rules-hands)（4つの面子と雀頭）を満たしているが、どの役の条件も**満たさない**手牌。中庸麻雀の標準ルールには**翻縛りがなく**、役のない手（俗に「チキンハンド」という）も和ることができ、得点は [hl]**1 点**[/] とします。

:::

この手牌は[刻子](rules-triplet)があるため[平和](pattern-1.1)ではなく、字牌の雀頭があるため[断么九](pattern-1.3)でもなく、鳴いていれば[門前清](pattern-1.2)でもありません。他に役がない場合、これが典型的な「チキンハンド」となります。

## 本アプリのオプション設定

対局設定には「**チキンハンドあり**」（初期設定は無効）があります。無効の場合、役のない手は和了できず「錯和」として扱われます。有効の場合、上記の通り [hl]**1 点**[/] で和了できます。

## 公式バリアント

公式なバリアントとして、**5点縛り**（5点以上の役が必要）を採用し、役のない手を「錯和」として扱うルールもあります。これは大会ごとの規程によるバリアントであり、標準ルールではありません。

[muted]チキンハンドは番号付きの役系列ではなく、基本和了形が成立していて他の役がない場合の最低保証点です。[/]
