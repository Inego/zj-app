# 翻牌

**3.1** · 翻牌 · [hl]**10 点／組**[/]

[門風（自風）](rules-seats)、[三元牌](rules-dragons)の[刻子](rules-triplet)／[槓子](rules-kong-types)。

[小三元](pattern-3.2.1)／[大三元](pattern-3.2.2)や[四喜系列](pattern-3.3)と複合する場合も例外なく加算されます（例えば大三元は必ず三元牌の刻子×3が含まれるので、130+10+10+10=160 点以上になります）。
