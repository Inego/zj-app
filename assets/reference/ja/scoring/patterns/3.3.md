# 四喜系列

**3.3** · 四喜系列

4種類の[風牌](rules-winds)（東、南、西、北）の刻子と雀頭の組み合わせ。系列内で最高得点の1つのみ数えます。門風の刻子が含まれる場合は[翻牌 (3.1)](pattern-3.1)（+10点）が加算されます。
