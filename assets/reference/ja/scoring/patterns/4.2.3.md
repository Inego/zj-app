# 四暗刻

**4.2.3** · 四暗刻 · [hl]**125 点**[/]

手には[暗刻](rules-triplet)／[暗槓](rules-kong-types)が四つ含まれる手。
「四暗刻」の手は必ず[門前清 (1.2)](pattern-1.2)（5点）と[対々和 (4.1)](pattern-4.1)（30点）も含まれるので、必ず [hl]**125 + 5 + 30 = 160 点**[/] 以上になります。
