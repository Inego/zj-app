# 字牌類

**3** · 字牌類

[字牌](rules-honors)（風牌および三元牌）の刻子や雀頭で構成される役。

## 役

- [**3.1** 翻牌](pattern-3.1) — [hl]**10**[/]（1組ごと）
- [**3.2** 三元系列](pattern-3.2)
- [**3.2.1** 小三元](pattern-3.2.1) — [hl]**40**[/]
- [**3.2.2** 大三元](pattern-3.2.2) — [hl]**130**[/]
- [**3.3** 四喜系列](pattern-3.3)
- [**3.3.1** 小三風](pattern-3.3.1) — [hl]**30**[/]
- [**3.3.2** 大三風](pattern-3.3.2) — [hl]**120**[/]
- [**3.3.3** 小四喜](pattern-3.3.3) — [hl]**320**[/]（役満貫）
- [**3.3.4** 大四喜](pattern-3.3.4) — [hl]**400**[/]（役満貫）
- [**3.4** 字一色](pattern-3.4) — [hl]**320**[/]（役満貫）
