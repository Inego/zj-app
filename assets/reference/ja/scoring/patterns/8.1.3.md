# 混么九

**8.1.3** · 混么九 · [hl]**100 点**[/]

即ち「混老頭」。么九数牌（1 または 9）と[字牌](rules-honors)のみで構成される[対々和 (4.1)](pattern-4.1)あるいは[七対子 (10.2)](pattern-10.2)の手。（[十三么九 (10.1)](pattern-10.1) の手は対象外。）
鳴きは自由です。
