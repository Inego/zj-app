# 刻子

まったく**同じ牌3枚**の組み合わせです（同色同数字の数牌、または同じ字牌）。

:::center
{333p} · {EEE} · {CCC}
:::

[風牌](rules-winds)や[三元牌](rules-dragons)は**同一の字牌**でのみ刻子（または槓子）を作ることができます。東南西北を1枚ずつ（{E}{S}{W}{N}）や白發中を1枚ずつ（{P}{F}{C}）集めても面子にはなりません。東が3枚あって初めて東の刻子となり、中が3枚あって初めて中の刻子となります。

他家の捨牌を鳴いて刻子を完成させることを**碰（ポン）**と呼びます。詳細は[吃・碰・槓](rules-claims)を参照してください。

同じ牌が4枚ある場合は、槓を宣言することで[槓子](rules-kong-types)として扱われます。
