# 三元牌

3種類の**[字牌](rules-honors)**です：

:::center
{P}{F}{C}
:::

- **白**（ハク／白板） — {P}
- **發**（ハツ／緑發） — {F}
- **中**（チュン／紅中） — {C}

三元牌には順序がありません。[順子](rules-sequence)を作ることはできず、**同一の牌**による[刻子](rules-triplet)または[槓子](rules-kong-types)のみを作ることができます。

三元牌の刻子または槓子は、すべてのプレイヤーにとって常に [翻牌 (3.1)](pattern-3.1)（1組につき+10点）になります。

## 役

三元牌の組み合わせによる役: [三元系列 (3.2)](pattern-3.2)（[小三元](pattern-3.2.1)／[大三元](pattern-3.2.2)）。
