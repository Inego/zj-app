# 基本和了形と特殊和了形

和了を宣言するためには、手牌が正式な**和了形**を満たしていなければなりません。第1類から第9類までの役は和了形の定義ではなく、和了形が成立している手に対して得点を付与するものです。

## 基本和了形

**4つの面子**と**1つの雀頭**（対子）。

面子は[順子](rules-sequence)、[刻子](rules-triplet)、[槓子](rules-kong-types)のいずれかです。槓子は1面子として数えます。雀頭となる[対子](rules-eyes)は4つの面子とは別に必要です。

通常の手牌は14枚で和了形となります（槓子がある場合は嶺上牌を補充しているため、牌の枚数が15枚や16枚になりますが合法です）。

### チキンハンド

基本和了形を満たしているものの、該当する**役が一つもない**手牌であっても、中庸麻雀の標準ルールでは和了することができます — これを[チキンハンド](scoring-chicken-hand)と呼び、[hl]**1**[/] 点となります。

一部のルールや大会では翻縛り（5点縛りなど）が採用され、役のない手が「錯和」とされる場合もあります。本アプリでは設定で「**チキンハンドあり**」を切り替え可能です。

## 特殊和了形（中庸麻雀）

4面子1雀頭の形式から外れることが許されるのは、[特殊和了形 (10)](pattern-10) に挙げられたもののみです：

- [十三么九 (10.1)](pattern-10.1)
- [七対子 (10.2)](pattern-10.2)

他の大きな役であっても、すべて基本和了形（または七対子）を満たす必要があります：

- [字一色 (3.4)](pattern-3.4) — 字牌のみで構成されますが、4刻子1対子または七対子の形が必要です。
- [対々和 (4.1)](pattern-4.1) — 4つの刻子／槓子と1つの対子が必要です。
