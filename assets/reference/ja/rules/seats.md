# 門風と輪荘

4人のプレイヤーは各局の巡目順に**東家、南家、西家、北家**と呼ばれます。あなたの**門風（自風）**は、その局で自分が座っている位置の風です。風牌については[風牌](rules-winds)を参照してください。

## 門風

自分の**門風**の刻子または槓子は [翻牌 (3.1)](pattern-3.1)（1組につき+10点）となります。これは[三元牌](rules-dragons)の刻子と同様です。

例えば、あなたが西家であれば {WWW} は翻牌ですが、{EEE} は翻牌になりません（あなたが東家である場合を除く）。

## 場風（圏風）は認めない

標準中庸麻雀では**場風（圏風）を認めません**。したがって、翻牌となる字牌は**門風**と**[三元牌](rules-dragons)**のみです。門風と場風が重なる「ダブ東」のような役はありません。

## 東家と輪荘

東家がその局の親（荘家）となります。局の最初の巡目で成立する特別な役：

- [天和 (9.4.1)](pattern-9.4.1) — 東家の配牌14枚による和了
- [地和 (9.4.2)](pattern-9.4.2) — 散家（子）の配牌13枚が聴牌しており、東家の**最初の捨牌**による和了

中庸麻雀の標準ルールでは、**局ごとに必ず輪荘し、連荘はありません**（東家が和了した場合でも連荘せず、次の局は元の南家が東家になります）。
