# 風牌

4種類の**[字牌](rules-honors)**です：

:::center
{E}{S}{W}{N}
:::

- **東** (トン)
- **南** (ナン)
- **西** (シャー)
- **北** (ペイ)

風牌には数字の順序がありません。したがって[順子](rules-sequence)を作ることはできず、**同一の風牌**による[刻子](rules-triplet)または[槓子](rules-kong-types)のみを作ることができます。

## 門風と風牌

各プレイヤーには、その局における自分の席に対応する**[門風（自風）](rules-seats)**があります。自分の門風の刻子または槓子は [翻牌 (3.1)](pattern-3.1) として10点になります。他の3家の風牌（客風）は翻牌になりません。

中庸麻雀では**場風（圏風）を認めません**。

## 役

複数の風牌の組み合わせによる役: [四喜系列 (3.3)](pattern-3.3)（小三風、大三風、小四喜、大四喜）。
