# 麻雀牌

標準的な麻雀牌のセットは全部で **136枚**（**34種類**、各 **4枚**）で構成されます。（中庸麻雀の標準ルールでは花牌や百搭牌（ジョーカー）は使用しません。）

## 数牌

数字の **1から9** までを持つ3つの[花色（スーツ）](rules-suits)に分かれます（全27種）：萬子、筒子、索子。

:::center
{1m}{5p}{9s}
:::

## 字牌

数字を持たない7種類の[字牌](rules-honors)があります（数字の順子を作ることはできません）：

- **[風牌](rules-winds)：** 東、南、西、北 — {E}{S}{W}{N}
- **[三元牌](rules-dragons)：** 白、發、中 — {P}{F}{C}

## 么九・中張と字牌

役の定義を読む際によく使われる用語：

- **么九数牌** — [数牌](rules-suits)の **1** または **9**
- **中張数牌** — [数牌](rules-suits)の **2〜8**
- **字牌** — すべての[字牌](rules-honors)（[風牌](rules-winds)または[三元牌](rules-dragons)）

[断么九 (1.3)](pattern-1.3) は手牌が中張数牌のみで構成される役です。[么九類 (8)](pattern-8) の役は1、9、および字牌に着目します。[翻牌 (3.1)](pattern-3.1) は特定の字牌の刻子に点数を与えます — 詳細は[門風と輪荘](rules-seats)を参照してください。
