# 面子と雀頭

**基本和了形**は**4つの面子**と**1つの雀頭**（対子）で構成されます。詳細は[基本和了形と特殊和了形](rules-hands)を参照してください。

各面子は以下のいずれかでなければなりません：

- **[順子](rules-sequence)** — 同一の[数牌](rules-suits)で連続する3枚の牌
- **[刻子](rules-triplet)** — 3枚のまったく同じ牌
- **[槓子](rules-kong-types)** — 4枚のまったく同じ牌（槓の宣言が必要）

手牌を完成させるための1組：

- **[雀頭（対子）](rules-eyes)** — 2枚のまったく同じ牌（面子ではありません）

:::

同じ牌4枚は槓を宣言することで1つの面子として数えられ、[嶺上牌](rules-kong-types)を1枚補充します。他家の捨牌を鳴いて面子を作るルールは[吃・碰・槓](rules-claims)を参照してください。
