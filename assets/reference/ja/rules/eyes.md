# 雀頭（対子）

基本和了形を完成させるための、まったく**同じ牌2枚**の組み合わせです（「雀頭」または「対子」「アタマ」と呼びます）。

:::center
{55s} · {WW}
:::

雀頭は面子では**ありません**。[基本和了形](rules-hands)では、4つの面子に加えてちょうど1つの雀頭が必要です（[七対子 (10.2)](pattern-10.2)などの特殊和了形を除く）。

どの牌でも雀頭にすることができます — 数牌、[風牌](rules-winds)、[三元牌](rules-dragons)のいずれも可能です。一部の役では雀頭に条件がある場合があります（例えば字牌の雀頭があると[断么九 (1.3)](pattern-1.3)にはならないなど）。
