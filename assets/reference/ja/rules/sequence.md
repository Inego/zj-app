# 順子

順子とは、**同一の[数牌](rules-suits)**で数字が連続する**ちょうど3枚**の組み合わせです。字牌で順子を作ることはできません。

:::center
{123m} · {567p} · {789s}
:::

4枚連続した牌は「4枚の順子」では**ありません**。例えば {3456m} は4枚あるため1つの面子にはならず、手牌の中で2つの部分（順子 {345m} と余りの {6m}、または順子 {456m} と余りの {3m}）に分けなければなりません。

順子は**3枚**で1組です。3枚同じ牌は[刻子](rules-triplet)であり、4枚同じ牌を槓したものは[槓子](rules-kong-types)です。4枚の順子という面子種別は存在しません。

上家（直前の手番のプレイヤー）の捨牌を鳴いて順子を完成させることを**吃（チー）**と呼びます。詳細は[吃・碰・槓](rules-claims)を参照してください。
