# 数牌

**数牌**とは、数字を持つ3つの花色の牌のことです。各花色に **1から9** まで9種類（各4枚）あり、3花色合わせて麻雀牌34種中 **27種類** を占めます。

## 萬子 (ワンズ)

漢数字。

:::center
{123456789m}
:::

## 筒子 (ピンズ)

円／銅銭の模様。

:::center
{123456789p}
:::

## 索子 (ソーズ)

竹／紐の模様。

:::center
{123456789s}
:::

数牌のみが**[順子](rules-sequence)**（同じ花色で連続する3枚）を作ることができます。**[字牌](rules-honors)**（[風牌](rules-winds)と[三元牌](rules-dragons)）は数牌ではないため、順子を作ることはできません。詳細は[麻雀牌](rules-tiles)を参照してください。

得点計算では、手牌に含まれる花色の構成が重要になります：

- **単一の花色** — [一色類 (2)](pattern-2)（混一色または清一色）
- **同一花色の同一順子** — [一色同順系列 (5)](pattern-5)
- **3色すべてで同一数字** — [三色類 (6)](pattern-6)
- **同一花色で連続する面子** — [連続類 (7)](pattern-7)
