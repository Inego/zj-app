# 槓子

**槓子**とは、まったく同じ牌4枚からなり、**槓（カン）**の宣言を行って成立する面子です。槓をした後は、牌山の末尾から**嶺上牌（補充牌）**を1枚引き、通常通り牌を1枚捨てます（嶺上牌で和了した場合を除く：[嶺上開花 (9.2)](pattern-9.2)）。

## 暗槓

手牌の中で同じ牌4枚を自分で揃えて槓を宣言します。中庸麻雀では、不正防止のために暗槓の際も4枚の牌を即座に開示して確認します。暗槓は[門前清 (1.2)](pattern-1.2)を**崩しません**。

暗槓に対して搶槓することは**できません**。

## 大明槓

手牌に暗刻（3枚）があり、他家が捨てた4枚目を鳴いて槓を宣言します。成立後、卓上に4枚を開示して明槓となります。

## 小明槓（加槓）

すでにポンしている明刻に対して、自分で引いてきた4枚目を加えて槓を宣言します。小明槓に対して他家が和了できる場合、その牌を鳴いて[搶槓](rules-winning)でロン和することができます。

## 槓の宣言後

- 槓子は卓上に固定され、組み替えることはできません。
- **嶺上牌**を1枚引き、打牌します（または嶺上開花で和了）。
- 槓子は[基本和了形](rules-hands)の1面子として数えられ、[槓子系列 (4.3)](pattern-4.3)の役の対象となります。
