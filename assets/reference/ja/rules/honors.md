# 字牌

**字牌**とは、数字を持たない7種類の牌のことです。4種類の**[風牌](rules-winds)**と3種類の**[三元牌](rules-dragons)**からなります。[数牌](rules-suits)のような数字の大小関係はなく、順子を作ることはできません。

:::center
{E}{S}{W}{N} · {P}{F}{C}
:::

## 字牌で作れる組み合わせ

- **同一の牌** 3枚または4枚で[刻子](rules-triplet)や[槓子](rules-kong-types)（東3枚、中3枚など）
- 同一の牌 2枚で[雀頭](rules-eyes)（対子）

字牌で[順子](rules-sequence)を作ることは**できません**。東南西北を1枚ずつ、あるいは白發中を1枚ずつ集めても面子にはなりません。

## 分類

- **[風牌](rules-winds)** — 東、南、西、北
- **[三元牌](rules-dragons)** — 白、發、中

## 得点計算

- [翻牌 (3.1)](pattern-3.1) — 門風および三元牌の刻子／槓子（1組につき10点）
