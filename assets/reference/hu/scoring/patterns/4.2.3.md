# Négy zárt terc

**4.2.3** · 四暗刻 · [hl]**125 pont**[/]

Négy zárt terc vagy zárt kong. A más sorozatokból származó magától értetődő
kombinációk továbbra is számítanak (pl. [Zárt kéz](pattern-1.2) +
[Csupa terc](pattern-4.1) → legalább 160 pont).

[muted]4.2-es sorozat — a legmagasabb zárt terc szint.[/]
