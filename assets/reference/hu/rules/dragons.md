# Sárkányok

Három **[kitüntetésminta](rules-honors)** — nem számozott [szín](rules-suits):

:::center
{P}{F}{C}
:::

- **Fehér** (白) — {P}
- **Zöld** (發) — {F}
- **Vörös** (中) — {C}

A sárkányoknak nincs sorrendjük. Nem alkothatnak [sorozatokat](rules-sequence)
— csak **ugyanabból** a mintából álló [terceket](rules-triplet) vagy [kongokat](rules-kong-types)
(három Vörös, nem „mindegyik sárkányból egy”).

Bármelyik sárkányból alkotott terc vagy kong mindig
[Értékes kitüntetés (3.1)](pattern-3.1) (+10 csoportonként), minden játékos számára.
