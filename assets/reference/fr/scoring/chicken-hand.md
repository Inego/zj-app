# Main sans figure

雞和 · [hl]**1 point**[/]

Une [main régulière](rules-hands) complète (quatre combinaisons + yeux) qui ne
correspond à **aucune** des combinaisons de score des catégories 1 à 9. Le Zung
Jung standard n'a **aucun minimum** : cette victoire sans combinaison reste
légale et marque un [hl]**1**[/] point symbolique.

:::center
{567s}{333m}{456m}{234s}{FF}
:::

Cette forme comporte un [brelan](rules-triplet) (donc pas
[Toutes suites](pattern-1.1)), des yeux d'honneur (donc pas
[Sans extrémités](pattern-1.3)), et — si une combinaison a été réclamée — est
ouverte (donc pas [Main fermée](pattern-1.2)). Sans autre combinaison, c'est une
main sans figure.

## Règle locale dans cette application

La configuration de partie propose **Autoriser les mains sans figure** (désactivé
par défaut). Lorsque c'est désactivé, une main sans figure pure ne peut pas
déclarer Hu (elle est traitée comme une fausse victoire). Lorsque c'est activé,
elle marque [hl]**1**[/] comme ci-dessus.

## Variante (officielle)

Certains tournois utilisent un **minimum de 5 points** ; les mains sans figure sont
alors illégales. C'est une option locale/événementielle, pas les règles standard
par défaut.

[muted]La main sans figure n'est pas une série de combinaisons numérotée — c'est le
score résiduel quand une main régulière légale n'a aucun point de combinaison.[/]
