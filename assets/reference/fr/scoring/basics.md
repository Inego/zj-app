# Bases du score

Le Zung Jung est un système additif **basé sur les combinaisons** (v3.3). Seule
la main gagnante est comptée. Il n'y a pas de plancher de points de base (副底) :
la valeur de la main est la somme des valeurs des combinaisons uniquement.

## Règle additive

- Comptez les combinaisons de **séries différentes**.
- Au sein d'une même série, ne comptez qu'**une seule** (en général la plus
  haute qui s'applique).
- **Exception — [Honneur de valeur (3.1)](pattern-3.1) :** +10 **par**
  combinaison qualifiante ; s'accumule avec les autres combinaisons d'honneurs.

Les séries partagent les deux premiers niveaux d'ID (par exemple toutes les
[4.2.x](pattern-4.2) forment une série). Voir chaque page de combinaison pour
ses notes de série.

## Main sans figure

Une [main régulière](rules-hands) complète **sans** combinaison de score vaut
[hl]**1**[/] point — voir [Main sans figure](scoring-chicken-hand). Il n'y a pas
de minimum dans le Zung Jung standard (un minimum optionnel de 5 points existe
comme variante).

## Limites

- **Limite composée :** si plusieurs combinaisons totalisent 320 ou plus, la
  main marque [hl]**320**[/] (les combinaisons restent conceptuellement
  présentes).
- **Limite listée :** une seule combinaison listée à 320+ marque **uniquement
  cette combinaison** (rien d'autre n'est ajouté). La combinaison listée la plus
  haute l'emporte si plusieurs s'appliquent.

## Paiement (formel)

Le gagnant reçoit toujours **3 × la valeur de la main**.

- **[Auto-pioche](rules-winning) :** chacun des trois autres paie la valeur
  complète de la main.
- **[Victoire sur défausse](rules-winning), valeur ≤ 25 :** chacun des trois
  paie la valeur complète de la main.
- **Victoire sur défausse, valeur > 25 :** chaque joueur non responsable paie
  **25** ; le défausseur paie **3×valeur − 50**.

Aucun [vent dominant](rules-seats) n'est reconnu. Le [vent de place](rules-seats)
et les [dragons](rules-dragons) sont les honneurs de valeur pour la combinaison
[3.1](pattern-3.1).
