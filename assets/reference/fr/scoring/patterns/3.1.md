# Honneur de valeur

**3.1** · 番牌 · [hl]**10 points / combinaison**[/]

Brelan ou kong de votre **[vent de place](rules-seats)** ou de n'importe quel
**[dragon](rules-dragons)**. Se compte **cumulativement par combinaison**
(+10 chacune). Il n'y a **aucun** [vent dominant](rules-seats) en Zung Jung. Les
**tuiles** de vent : [Vents](rules-winds).

S'accumule toujours avec [Petits trois dragons](pattern-3.2.1) /
[Grands trois dragons](pattern-3.2.2) et les [combinaisons de vents](pattern-3.3)
quand celles-ci s'appliquent aussi (par exemple [Grands trois dragons](pattern-3.2.2)
inclut toujours 3× Honneur de valeur → au moins 160).
