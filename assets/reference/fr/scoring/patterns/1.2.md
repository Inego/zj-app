# Main fermée

**1.2** · 門前清 · [hl]**5 points**[/]

[Main régulière](rules-hands) sans **aucune [combinaison ouverte](rules-concealed-open)**
avant la victoire. Gagner sur une défausse est autorisé. Un
**[kong caché](rules-kong-types)** ne rompt pas cette combinaison ; un kong
ouvert, si.

Les mains irrégulières ([catégorie 10](pattern-10)) **ne comptent pas** la Main
fermée.
