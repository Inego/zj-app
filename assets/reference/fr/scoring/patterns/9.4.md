# Bénédictions

**9.4** · 天地和

Bénédictions sur la toute première distribution : Ciel pour les 14 tuiles initiales d'Est, Terre pour une victoire non-Est sur la première défausse d'Est. Invalide si Est a déclaré un kong caché.
