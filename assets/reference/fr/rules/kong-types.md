# Kong

Un **kong** est quatre tuiles identiques, **déclarées** comme combinaison.
Après toute déclaration de kong, vous piochez une tuile de **remplacement** (à
l'extrémité du mur réservée à cet effet), puis vous défaussez habituellement —
sauf si ce remplacement fait gagner la main
([Victoire sur kong (9.2)](pattern-9.2)).

## Kong caché

Vous détenez les quatre en main et déclarez. En Zung Jung, les quatre tuiles
sont révélées pour vérification. Un kong caché ne rompt **pas** la
[Main fermée (1.2)](pattern-1.2).

Un kong caché **ne peut pas** être volé.

## Grand kong exposé

Vous détenez un brelan **caché** et réclamez la quatrième tuile sur la défausse
de quelqu'un. Le kong est ouvert.

## Petit kong exposé

Vous avez déjà un **pung ouvert** et ajoutez la quatrième tuile de votre main
(souvent après l'avoir piochée). Promouvoir le pung en kong est le moment où les
autres peuvent [voler le kong](rules-winning) si cette tuile complète leur
victoire.

## Après la déclaration

- Le kong est verrouillé ; vous ne pouvez pas le réorganiser.
- Piochez la tuile de **remplacement**, puis défaussez (ou gagnez sur le remplacement).
- Le kong compte comme une combinaison pour une [main régulière](rules-hands) et
  pour les [combinaisons de kong (4.3)](pattern-4.3).
