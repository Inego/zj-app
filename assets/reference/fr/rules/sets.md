# Combinaisons et paire

Une **main régulière** est construite à partir de **combinaisons** plus les
**yeux** (une paire). Voir
[Mains régulières et irrégulières](rules-hands).

Chaque combinaison est l'une des suivantes :

- **[Suite](rules-sequence)** — trois numéros consécutifs, même [couleur](rules-suits)
- **[Brelan](rules-triplet)** — trois tuiles identiques
- **[Kong](rules-kong-types)** — quatre tuiles identiques, déclarées

Plus la paire finale :

- **[Yeux](rules-eyes)** — deux tuiles identiques (pas une combinaison)

Les kongs comptent comme combinaisons une fois déclarés et nécessitent une
[pioche de remplacement](rules-kong-types). Réclamer des combinaisons sur les
défausses est traité dans [Réclamations](rules-claims).
