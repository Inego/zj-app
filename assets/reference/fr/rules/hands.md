# Mains régulières et irrégulières

Pour gagner, la main doit correspondre à une **forme gagnante** légale. Les
combinaisons de score des catégories 1 à 9 ne créent **pas** de formes
alternatives — elles valorisent seulement une main déjà complète.

## Main régulière

**Quatre combinaisons** + **une paire** (yeux).

Chaque combinaison est une [suite](rules-sequence), un [brelan](rules-triplet)
ou un [kong](rules-kong-types). Les kongs comptent comme combinaisons une fois
déclarés. Les [yeux](rules-eyes) finaux (la paire) se situent hors des quatre
combinaisons.

Exemple de forme (schématique) : quatre groupes + une paire → 14 tuiles une
fois complète (avec des kongs, les kongs déclarés et un remplacement gardent la
main légale).

### Main sans figure

Une main régulière complète **sans** aucune combinaison de score reste une
victoire légale dans le Zung Jung standard — la
[main sans figure](scoring-chicken-hand) marque [hl]**1**[/] point.

Certains joueurs et tournois interdisent les mains sans figure (elles comptent
comme une fausse victoire). Cette option locale est prise en charge dans cette
application dans la configuration de partie (**Autoriser les mains sans figure**).

## Mains irrégulières (Zung Jung)

Seules les formes listées sous [Mains irrégulières (10)](pattern-10) peuvent
gagner sans la forme à quatre combinaisons :

- [Treize extrémités (10.1)](pattern-10.1)
- [Sept paires (10.2)](pattern-10.2)

Exemples qui nécessitent encore une forme régulière (ou Sept paires) :

- [Tous honneurs (3.4)](pattern-3.4) — toutes les tuiles sont des honneurs, mais
  il faut encore quatre combinaisons + yeux **ou** Sept paires
- [Tous brelans (4.1)](pattern-4.1) — quatre brelans/kongs + yeux
