# Yeux (paire)

Deux tuiles **identiques** qui complètent une main régulière (la « paire » /
les « yeux »).

:::center
{55s} · {WW}
:::

Les yeux ne sont **pas** une combinaison. Il vous faut exactement une paire dans
une [main régulière](rules-hands) (sauf si vous gagnez avec une forme
irrégulière comme [Sept paires](pattern-10.2)).

Les yeux peuvent être n'importe quelle face — numéros, [vents](rules-winds) ou
[dragons](rules-dragons). Les combinaisons de score tiennent parfois compte de
ce que sont les yeux (par exemple, des yeux d'honneur bloquent
[Sans extrémités (1.3)](pattern-1.3)), mais la forme de la main elle-même
n'exige qu'une paire.
