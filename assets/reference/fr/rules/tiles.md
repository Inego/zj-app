# Tuiles

Un jeu de compétition standard compte **136 tuiles** : **34 faces**, chacune
imprimée **4** fois. (Les fleurs et les jokers ne sont pas utilisés dans le
Zung Jung standard.)

## Tuiles de couleur

Trois **[couleurs](rules-suits)** numérotées, rangs **1–9** chacune
(27 faces) : Caractères, Cercles, Bambous.

{1m}{5p}{9s}
:::

## Tuiles d'honneur

Sept **[honneurs](rules-honors)** (sans ordre de rang pour les suites) :

- **[Vents](rules-winds) :** Est, Sud, Ouest, Nord — {E}{S}{W}{N}
- **[Dragons](rules-dragons) :** Blanc, Vert, Rouge — {P}{F}{C}

## Extrémités, simples, honneurs

Étiquettes utiles pour lire les combinaisons de score :

- **Extrémité** — [couleur](rules-suits) **1** ou **9**
- **Simple** — [couleur](rules-suits) **2–8**
- **Honneur** — toute tuile [d'honneur](rules-honors) ([vents](rules-winds) ou
  [dragons](rules-dragons))

[Sans extrémités (1.3)](pattern-1.3) signifie uniquement des simples — aucune
extrémité ni honneur. Les combinaisons des [Extrémités](pattern-8) concernent
les 1, les 9, et souvent les honneurs. [Honneur de valeur (3.1)](pattern-3.1)
fait marquer certaines combinaisons d'honneurs —
voir [Places et vents](rules-seats).
