# Очі (пара)

Дві **однакові** кістки, що завершують стандартну руку («пара» / «очі»).

:::center
{55s} · {WW}
:::

Очі **не** є сетом. Вам потрібна рівно одна пара в
[стандартній руці](rules-hands) (якщо тільки ви не виграєте нестандартною формою,
такою як [Сім пар](pattern-10.2)).

Очима може бути будь-який малюнок — номерні кістки, [вітри](rules-winds) або
[дракони](rules-dragons). Комбінації підрахунку очок іноді враховують малюнок
очей (наприклад, очі з благородних кісток виключають [Усі прості (1.3)](pattern-1.3)),
але сама по собі форма руки вимагає лише однієї пари.
