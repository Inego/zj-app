# Стандартні та нестандартні руки

Щоб виграти, рука має відповідати дозволеній **виграшній формі**. Комбінації
в категоріях 1–9 **не** створюють альтернативних форм — вони лише оцінюють
руку, яка вже є зібраною.

## Стандартна рука

**Чотири сети** + **одна пара** (очі).

Кожен сет — це [послідовність](rules-sequence), [трійка](rules-triplet) або
[конг](rules-kong-types). Конги зараховуються як сети після їх оголошення.
Завершальні [очі](rules-eyes) (пара) стоять окремо від чотирьох сетів.

Приклад форми: чотири групи + пара → 14 кісток у зібраному стані
(за наявності конгів оголошені четвірки та взяті додаткові кістки підтримують правильний баланс руки).

### Рука без комбінацій

Зібрана стандартна рука **без жодних** залікових комбінацій усе одно є законним
виграшем у стандартному Чжун-юн — [рука без комбінацій](scoring-chicken-hand)
оцінюється в [hl]**1**[/] очко.

Деякі гравці та турніри забороняють руки без комбінацій (вони вважаються помилковим виграшем).
Ця опція підтримується в налаштуваннях гри цього застосунку (**Дозволити руки без комбінацій**).

## Нестандартні руки (Чжун-юн)

Лише форми, перелічені в розділі [Нестандартні руки (10)](pattern-10), можуть вигравати
без форми з чотирьох сетів:

- [Тринадцять сиріт (10.1)](pattern-10.1)
- [Сім пар (10.2)](pattern-10.2)

Приклади, що все одно вимагають стандартної форми (або Семи пар):

- [Усі благородні (3.4)](pattern-3.4) — усі кістки благородні, але все одно чотири сети
  + пара **або** Сім пар
- [Усі панги (4.1)](pattern-4.1) — чотири трійки/конги + пара
