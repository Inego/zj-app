# Благородні

**Благородні** — це сім малюнків без масті: чотири **[вітри](rules-winds)**
та три **[дракони](rules-dragons)**. Вони не належать до номерних
[мастей](rules-suits) і **не мають рангового порядку** для послідовностей.

:::center
{E}{S}{W}{N} · {P}{F}{C}
:::

## Що утворюють благородні кістки

- [Трійки (панги)](rules-triplet) та [конги](rules-kong-types) **однакового**
  малюнка (три Сходи, три Червоні, …)
- [Очі (пару)](rules-eyes) (дві однакові кістки)

Вони **не можуть** утворювати [послідовності (чоу)](rules-sequence). По одній
кістці кожного вітру чи кожного дракона — це не сет.

## Родини

- **[Вітри](rules-winds)** — Схід, Південь, Захід, Північ
- **[Дракони](rules-dragons)** — Білий, Зелений, Червоний
