# Трійка (панг)

Три **однакові** кістки (одного малюнка).

:::center
{333p} · {EEE} · {CCC}
:::

[Вітри](rules-winds) та [дракони](rules-dragons) утворюють трійки (або конги)
лише **однакового** малюнка — а не «сет з усіх вітрів» чи «сет з усіх драконів».
Наявність по одній кістці кожного вітру ({E}{S}{W}{N}) або кожного дракона
({P}{F}{C}) — це просто три чи чотири різні кістки, а не сет. Вам потрібні три
Сходи для трійки Сходу, три Червоні для трійки Червоного дракона і так далі.

(Виграшні комбінації, такі як [Великі чотири вітри (3.3.4)](pattern-3.3.4), все одно
вимагають справжніх **трійок** вітрів — зібрати по одній кістці кожного недостатньо.)

Оголошення третьої копії зі скидання будь-якого гравця називається **панг**. Див.
[Оголошення](rules-claims).

Чотири однакові кістки, оголошені як сет, є [конгом](rules-kong-types),
а не довшою трійкою.
