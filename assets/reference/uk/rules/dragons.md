# Дракони

Три **[благородні](rules-honors)** малюнки — не номерна [масть](rules-suits):

:::center
{P}{F}{C}
:::

- **Білий** (白) — {P}
- **Зелений** (發) — {F}
- **Червоний** (中) — {C}

У драконів немає рангового порядку. Вони не утворюють [послідовностей](rules-sequence) —
лише [трійки (панги)](rules-triplet) або [конги](rules-kong-types) **однакового**
малюнка (три Червоні, а не «по одному кожного дракона»).

Будь-яка трійка або конг дракона завжди вважається
[Цінними благородними (3.1)](pattern-3.1) (+10 за сет) для кожного гравця.
