# Однакові послідовності

**5.1** · 一般高類

Сходи однакових послідовностей в одній [масті](rules-suits). Зараховується лише найвищий рівень, що підходить.

## Комбінації

- [**5.1.1** Два однакові чоу](pattern-5.1.1) — [hl]**10**[/]
- [**5.1.2** Двічі по два однакові чоу](pattern-5.1.2) — [hl]**60**[/]
- [**5.1.3** Три однакові чоу](pattern-5.1.3) — [hl]**120**[/]
- [**5.1.4** Чотири однакові чоу](pattern-5.1.4) — [hl]**480**[/] (гранична рука)
