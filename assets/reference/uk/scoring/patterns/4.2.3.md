# Чотири закриті панги

**4.2.3** · 四暗刻 · [hl]**125 очок**[/]

Чотири закриті трійки або закриті конги. Приховані комбінації в
інших серіях усе одно зараховуються (наприклад, [Закрита рука](pattern-1.2) +
[Усі панги](pattern-4.1) → щонайменше 160).

[muted]Серія 4.2 — найвищий рівень закритих троєк.[/]
