# Цінні благородні

**3.1** · 番牌 · [hl]**10 очок / сет**[/]

Трійка або конг вашого **[вітру місця](rules-seats)** або будь-якого
**[дракона](rules-dragons)**. Рахується **сукупно за кожен сет** (+10 за кожен).
У Чжун-юн **немає** [переважального вітру](rules-seats). Кістки
**вітрів:** [Вітри](rules-winds).

Завжди підсумовується з [Малими трьома драконами](pattern-3.2.1) /
[Великими трьома драконами](pattern-3.2.2) та [комбінаціями вітрів](pattern-3.3),
коли вони також підходять (наприклад, [Великі три дракони](pattern-3.2.2)
завжди включають 3× Цінні благородні → щонайменше 160).
