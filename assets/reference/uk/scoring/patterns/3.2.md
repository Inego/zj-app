# Дракони

**3.2** · 三元

Комбінації драконів: два сети драконів плюс очі з драконів (малі) або три трійки/конги драконів (великі). Завжди також зараховують [Цінні благородні (3.1)](pattern-3.1).

## Комбінації

- [**3.2.1** Малі три дракони](pattern-3.2.1) — [hl]**40**[/] (завжди +2×[3.1](pattern-3.1) → ≥60)
- [**3.2.2** Великі три дракони](pattern-3.2.2) — [hl]**130**[/] (завжди +3×[3.1](pattern-3.1) → ≥160)
