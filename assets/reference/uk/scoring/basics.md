# Основи підрахунку очок

Чжун-юн — це **комбінаційна** адитивна система (v3.3). Очки нараховуються
лише за виграшну руку. Базових очок (фу / 副底) немає: вартість
руки складається виключно із суми вартостей комбінацій.

## Правило додавання

- Рахуються комбінації з **різних серій**.
- У межах однієї серії зараховується **лише одна** комбінація (зазвичай найвища
  з тих, що підходять).
- **Виняток — [Цінні благородні (3.1)](pattern-3.1):** +10 **за кожен** підхожий сет;
  підсумовується з іншими комбінаціями благородних.

Серії мають однакові перші два рівні ID (наприклад, усі [4.2.x](pattern-4.2) належать до однієї
серії). Примітки до кожної серії дивіться на сторінці відповідної комбінації.

## Рука без комбінацій

Зібрана [стандартна рука](rules-hands) **без жодних** залікових комбінацій
коштує [hl]**1**[/] очко — див. [Рука без комбінацій](scoring-chicken-hand).
У стандартному Чжун-юн немає мінімального порогу очок (варіант із 5-очковим
мінімумом існує як необов'язкове домашнє правило).

## Ліміти

- **Сукупний ліміт:** якщо кілька комбінацій у сумі дають 320 або більше,
  рука оцінюється в [hl]**320**[/] очок (комбінації концептуально зберігаються).
- **Гранична рука за списком:** якщо окрема комбінація коштує 320+, зараховується
  **тільки ця комбінація** (нічого іншого не додається). Якщо підходять кілька таких
  комбінацій, обирається найвища.

## Розрахунок виплат

Переможець завжди отримує **3 × вартість руки**.

- **[Взяття зі стіни](rules-winning):** кожен із трьох інших гравців платить повну вартість руки.
- **[Виграш на скиданні](rules-winning), вартість ≤ 25:** кожен із трьох гравців платить повну
  вартість руки.
- **Виграш на скиданні, вартість > 25:** кожен невинний гравець платить
  **25**; той, хто скинув, платить **3×вартість − 50**.

[Переважальний вітер](rules-seats) не використовується. [Вітер місця](rules-seats) та
[дракони](rules-dragons) є цінними благородними для комбінації
[3.1](pattern-3.1).
