# Regular & irregular hands

To win, the hand must match a legal **winning shape**. Scoring patterns
in categories 1–9 do **not** create alternate shapes — they only value a
hand that is already complete.

## Regular hand

**Four sets** + **one pair** (eyes).

Each set is a [sequence](rules-sequence), [triplet](rules-triplet), or
[kong](rules-kong-types). Kongs count as sets once declared. The
completing [eyes](rules-eyes) (pair) sit outside the four sets.

Example shape (schematic): four groups + a pair → 14 tiles when complete
(with kongs, declared fours and a supplement keep the hand legal).

### Patternless hand

A complete regular hand with **no** scoring patterns is still a legal
win in standard Zung Jung — the [patternless hand](scoring-chicken-hand)
scores [hl]**1**[/] point.

Some players and tournaments forbid patternless hands (they count as a
false win). That house option is supported in this app under game
setup (**Allow patternless hands**).

## Irregular hands (Zung Jung)

Only the shapes listed under [Irregular Hands (10)](pattern-10) may win
without the four-set form:

- [Thirteen Terminals (10.1)](pattern-10.1)
- [Seven Pairs (10.2)](pattern-10.2)

Examples that still need a regular (or Seven Pairs) shape:

- [All Honors (3.4)](pattern-3.4) — all tiles honors, but still four sets
  + eyes **or** Seven Pairs
- [All Triplets (4.1)](pattern-4.1) — four triplets/kongs + eyes
