# Sequence

A sequence is **exactly three** consecutive numbers in the
**same [suit](rules-suits)**. Honors cannot form sequences.

:::center
{123m} · {567p} · {789s}
:::

A longer run is **not** “a better sequence.” For example {3456m} is four
tiles, not one set: you still need to group them as **two** pieces of the
hand (for instance a sequence {345m} with a spare {6m}, or {456m} with a
spare {3m}). Those four tiles never count as a single four-tile sequence.

Only **3** in a row is a set. Only **3** identical tiles is a
[triplet](rules-triplet) (and only **4** identical is a
[kong](rules-kong-types) — a different kind of set, not a longer
sequence).

Claiming a sequence from a discard is a **chow** (only from the player
on your left — the upper seat). See [Claims](rules-claims).
