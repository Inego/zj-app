# Tiles

A standard competition set has **136 tiles**: **34 designs**, each
printed **4** times. (Flowers and jokers are not used in standard
Zung Jung.)

## Suited tiles

Three numbered **[suits](rules-suits)**, ranks **1–9** each
(27 designs): Characters, Dots, Bamboos.

:::center
{1m}{5p}{9s}
:::

## Honor tiles

Seven **[honors](rules-honors)** (no rank order for sequences):

- **[Winds](rules-winds):** East, South, West, North — {E}{S}{W}{N}
- **[Dragons](rules-dragons):** White, Green, Red — {P}{F}{C}

## Terminals, simples, honors

Useful labels when reading scoring patterns:

- **Terminal** — [suited](rules-suits) **1** or **9**
- **Simple** — [suited](rules-suits) **2–8**
- **Honor** — any [honor](rules-honors) tile ([winds](rules-winds) or
  [dragons](rules-dragons))

[No Terminals (1.3)](pattern-1.3) means simples only — no terminals and
no honors. [Terminals](pattern-8) patterns care about 1s, 9s, and often
honors. [Value Honor (3.1)](pattern-3.1) scores certain honor sets —
see [Seats & winds](rules-seats).
