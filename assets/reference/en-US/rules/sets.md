# Sets & eyes

A **regular hand** is built from **sets** plus **eyes** (a pair). See
[Regular & irregular hands](rules-hands).

Each set is one of:

- **[Sequence](rules-sequence)** — three consecutive numbers, same [suit](rules-suits)
- **[Triplet](rules-triplet)** — three identical tiles
- **[Kong](rules-kong-types)** — four identical tiles, declared

Plus the completing pair:

- **[Eyes](rules-eyes)** — two identical tiles (not a set)

:::center
{123m} · {333p} · {1111s} · {55p}
:::

Kongs count as sets once declared and require a
[supplement draw](rules-kong-types). Claiming sets from discards is
covered under [Claims](rules-claims).
