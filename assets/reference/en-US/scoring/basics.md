# Scoring basics

Zung Jung is a **pattern-based** additive system (v3.3). Only the
winning hand is scored. There is no basic point floor (副底): the
hand value is the sum of pattern values only.

## Additive rule

- Count patterns from **different series**.
- Within the same series, count **only one** (usually the highest
  that fits).
- **Exception — [Value Honor (3.1)](pattern-3.1):** +10 **per** qualifying set;
  stacks with other honor patterns.

Series share the same first two ID levels (e.g. all [4.2.x](pattern-4.2) are one
series). See each pattern page for its series notes.

## Patternless hand

A complete [regular hand](rules-hands) with **no** scoring patterns is
worth [hl]**1**[/] point — see [Patternless hand](scoring-chicken-hand).
There is no minimum in standard Zung Jung (an optional 5-point
minimum exists as a variant).

## Limits

- **Compound limit:** if several patterns sum to 320 or more, the
  hand scores [hl]**320**[/] (patterns still conceptually present).
- **Listed limit:** a single pattern listed at 320+ scores **only
  that pattern** (nothing else is added). Highest listed pattern
  wins if several apply.

## Payoff (formal)

Winner always receives **3 × hand value**.

- **[Self-draw](rules-winning):** each of the other three pays the full hand value.
- **[Win on discard](rules-winning), value ≤ 25:** each of the three pays the full
  hand value.
- **Win on discard, value > 25:** each non-responsible player pays
  **25**; the discarder pays **3×value − 50**.

No [prevailing wind](rules-seats) is recognized. [Seat wind](rules-seats) and
[dragons](rules-dragons) are the value honors for pattern
[3.1](pattern-3.1).
