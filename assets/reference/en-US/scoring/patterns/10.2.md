# Seven Pairs

**10.2** · 七對子 · [hl]**30 points**[/]

Seven pairs. Four identical tiles count as **two pairs** if no
kong was declared. Does **not** count [Concealed Hand (1.2)](pattern-1.2).

Cannot count patterns that require triplets, kongs, or
sequences. Other patterns still apply (e.g. [one-suit](pattern-2),
[terminals](pattern-8), [honors](pattern-3)).
