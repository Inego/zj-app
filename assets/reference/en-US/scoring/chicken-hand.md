# Patternless hand

雞和 · [hl]**1 point**[/]

A complete [regular hand](rules-hands) (four sets + eyes) that matches
**none** of the scoring patterns in categories 1–9. Standard Zung Jung
has **no minimum**: that patternless win is still legal and scores a
token [hl]**1**[/] point.

:::center
{567s}{333m}{456m}{234s}{FF}
:::

This shape has a [triplet](rules-triplet) (not [All Sequences](pattern-1.1)),
honor eyes (not [No Terminals](pattern-1.3)), and — if any set was
claimed — is open (not [Concealed Hand](pattern-1.2)). With no other
patterns, it is a patternless hand.

## House rule in this app

Game setup includes **Allow patternless hands** (off by default). When off,
a pure patternless hand cannot declare Hu (it is treated as a false win).
When on, it scores [hl]**1**[/] as above.

## Variant (official)

Some tournaments use a **5-point minimum**; patternless hands are then
illegal. That is a house/event option, not the default standard rules.

[muted]The patternless hand is not a numbered pattern series — it is the residual
score when a legal regular hand has zero pattern points.[/]
