# Dragones

**3.2** · 三元

Combinaciones de dragones: dos grupos de dragones más ojos de dragón (pequeños) o tres tríos/kongs de dragones (grandes). Cuenta siempre además [Honor de valor (3.1)](pattern-3.1).

## Patrones

- [**3.2.1** Tres dragones pequeños](pattern-3.2.1) — [hl]**40**[/] (siempre +2×[3.1](pattern-3.1) → ≥60)
- [**3.2.2** Tres dragones grandes](pattern-3.2.2) — [hl]**130**[/] (siempre +3×[3.1](pattern-3.1) → ≥160)

[muted]Serie 3.2 — cuenta solo una (la más alta que encaje).[/]
