# Silmät (pari)

Kaksi **identtistä** tiiltä, jotka täydentävät tavallisen käden ("pari" / "silmät").

:::center
{55s} · {WW}
:::

Silmät **eivät ole** sarja. Tarvitset tarkalleen yhden parin [tavallisessa kädessä](rules-hands) (ellet voita poikkeuksellisella muodolla, kuten [Seitsemän paria](pattern-10.2)).

Silmät voivat olla mistä tahansa kuviosta — numeroita, [tuulia](rules-winds) tai [lohikäärmeitä](rules-dragons). Pistekuviot huomioivat toisinaan parin laadun (esimerkiksi arvotiilipari estää kuvion [Ei reunoja (1.3)](pattern-1.3)), mutta itse käden muoto vaatii vain yhden parin.
