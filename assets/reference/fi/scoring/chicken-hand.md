# Kuvioton käsi

雞和 · [hl]**1 piste**[/]

Täysi [tavallinen käsi](rules-hands) (neljä sarjaa + silmät), joka ei täytä **mitään** kategorioiden 1–9 pistekuvioista. Tavallisessa Zung Jungissa **ei ole minimiä**: tämä kuvioton voitto on silti laillinen ja tuottaa nimellisen [hl]**1**[/] pisteen.

:::center

:::

Tässä muodossa on [kolmoset](rules-triplet) (ei [Pelkkiä suoria](pattern-1.1)), arvotiilisilmät (ei [Ei reunoja](pattern-1.3)), ja — jos jokin sarja vaadittiin heitosta — se on avoin (ei [Suljettu käsi](pattern-1.2)). Ilman muita kuvioita se on kuvioton käsi.

## Talon sääntö tässä sovelluksessa

Peliasetuksissa on **Salli kuviottomat kädet** (oletuksena pois päältä). Kun se on pois päältä, pelkkä kuvioton käsi ei voi julistaa Hu-voittoa (se katsotaan virheelliseksi voitoksi). Kun se on päällä, se tuottaa [hl]**1**[/] pisteen kuten edellä.

## Virallinen variantti

Jotkin turnaukset käyttävät **5 pisteen minimiä**; kuviottomat kädet ovat silloin laittomia. Se on turnauskohtainen valinta, ei vakiosääntö.

[muted]Kuvioton käsi ei ole numeroitu kuviosarja — se on jäännöspistemäärä, kun laillisessa tavallisessa kädessä on nolla kuviopistettä.[/]
