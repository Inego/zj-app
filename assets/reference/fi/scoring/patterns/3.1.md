# Arvotiili

**3.1** · 番牌 · [hl]**10 pistettä / sarja**[/]

Oman **[istuintuulesi](rules-seats)** tai minkä tahansa **[lohikäärmeen](rules-dragons)** kolmoset tai kongi. Lasketaan **kumulatiivisesti sarjaa kohti** (+10 kukin). Zung Jungissa **ei ole** [vallitsevaa tuulta](rules-seats). Tuuli**tiilet:** [Tuulet](rules-winds).

Yhdistyy aina kuvioihin [Pienet kolme lohikäärmettä](pattern-3.2.1) / [Suuret kolme lohikäärmettä](pattern-3.2.2) ja [tuulikuvioihin](pattern-3.3), kun ne myös soveltuvat (esim. [Suuret kolme lohikäärmettä](pattern-3.2.2) sisältää aina 3× Arvotiili → vähintään 160).
