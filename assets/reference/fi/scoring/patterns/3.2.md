# Lohikäärmeet

**3.2** · 三元

Lohikäärmeyhdistelmät: kaksi lohikäärmesarjaa plus lohikäärmesilmät (pienet) tai kolme lohikäärmekolmosta/kongia (suuret). Laske aina lisäksi [Arvotiili (3.1)](pattern-3.1).

## Kuviot

- [**3.2.1** Pienet kolme lohikäärmettä](pattern-3.2.1) — [hl]**40**[/] (aina +2×[3.1](pattern-3.1) → ≥60)
- [**3.2.2** Suuret kolme lohikäärmettä](pattern-3.2.2) — [hl]**130**[/] (aina +3×[3.1](pattern-3.1) → ≥160)
