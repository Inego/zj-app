# Arvotiilet

**3** · 字牌

Arvotiilet ([istuintuuli](rules-seats) ja [lohikäärmeet](rules-dragons)), [lohikäärmeiden](rules-dragons) ja [tuulten](rules-winds) sarjayhdistelmät sekä pelkistä arvotiilistä koostuvat kädet.

[Arvotiili (**3.1**)](pattern-3.1) lasketaan **sarjaa kohti** ja se yhdistyy aina alla oleviin lohikäärme- ja tuulikuvioihin.
