# Čestné kameny

**3** · 字牌

Cenné čestné kameny ([vítr místa](rules-seats) a [draci](rules-dragons)),
kombinace sad [draků](rules-dragons) a [větrů](rules-winds) a ruky ze samých čestných kamenů.

[Cenný čestný kámen (**3.1**)](pattern-3.1) se sčítá **za každou sadu** a vždy se kombinuje se vzorci draků a větrů níže.

## Vzorce

- [**3.1** Cenný čestný kámen](pattern-3.1) — [hl]**10 / sada**[/] (sčítá se)
- [**3.2** Draci](pattern-3.2) (série)
- [**3.2.1** Malí tři draci](pattern-3.2.1) — [hl]**40**[/]
- [**3.2.2** Velcí tři draci](pattern-3.2.2) — [hl]**130**[/]
- [**3.3** Větry](pattern-3.3) (série)
- [**3.3.1** Malé tři větry](pattern-3.3.1) — [hl]**30**[/]
- [**3.3.2** Velké tři větry](pattern-3.3.2) — [hl]**120**[/]
- [**3.3.3** Malé čtyři větry](pattern-3.3.3) — [hl]**320**[/] (uvedený limit)
- [**3.3.4** Velké čtyři větry](pattern-3.3.4) — [hl]**400**[/] (uvedený limit)
- [**3.4** Všechny čestné kameny](pattern-3.4) — [hl]**320**[/] (uvedený limit)
