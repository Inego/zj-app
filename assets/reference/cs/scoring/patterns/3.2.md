# Draci

**3.2** · 三元

Kombinace draků: dvě sady draků plus dračí oči (malí), nebo tři trojice/kongy draků (velcí). Vždy se navíc počítá [Cenný čestný kámen (3.1)](pattern-3.1).

## Vzorce

- [**3.2.1** Malí tři draci](pattern-3.2.1) — [hl]**40**[/] (vždy +2×[3.1](pattern-3.1) → ≥60)
- [**3.2.2** Velcí tři draci](pattern-3.2.2) — [hl]**130**[/] (vždy +3×[3.1](pattern-3.1) → ≥160)
