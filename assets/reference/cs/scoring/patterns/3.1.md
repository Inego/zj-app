# Cenný čestný kámen

**3.1** · Cenný čestný kámen · [hl]**10 bodů / sada**[/]

Trojice nebo kong tvého **[větru místa](rules-seats)** nebo kteréhokoli
**[draka](rules-dragons)**. Počítá se **kumulativně za sadu** (+10 za každou).
V Zung Jung **není** žádný [vítr kola](rules-seats). Kameny
**větrů:** [Větry](rules-winds).

Vždy se sčítá s [Malými třemi draky](pattern-3.2.1) /
[Velkými třemi draky](pattern-3.2.2) a se [vzorci větrů](pattern-3.3),
když platí i ty (např. [Velcí tři draci](pattern-3.2.2)
vždy obsahují 3× Cenný čestný kámen → nejméně 160).
