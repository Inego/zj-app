# Kamienie honorowe

**3** · 字牌

Punktowane honory ([wiatr miejsca](rules-seats) i [smoki](rules-dragons)), kombinacje grup [smoków](rules-dragons) i [wiatrów](rules-winds) oraz ręce złożone z samych honorów.

[Punktowany honor (**3.1**)](pattern-3.1) sumuje się **za każdą grupę** i zawsze łączy się z poniższymi układami smoków/wiatrów.

## Układy

- [**3.1** Punktowany honor](pattern-3.1) — [hl]**10 / grupa**[/] (sumowalny)
- [**3.2** Smoki](pattern-3.2) (seria)
- [**3.2.1** Małe trzy smoki](pattern-3.2.1) — [hl]**40**[/]
- [**3.2.2** Wielkie trzy smoki](pattern-3.2.2) — [hl]**130**[/]
- [**3.3** Wiatry](pattern-3.3) (seria)
- [**3.3.1** Małe trzy wiatry](pattern-3.3.1) — [hl]**30**[/]
- [**3.3.2** Wielkie trzy wiatry](pattern-3.3.2) — [hl]**120**[/]
- [**3.3.3** Małe cztery wiatry](pattern-3.3.3) — [hl]**320**[/] (limit wykazowy)
- [**3.3.4** Wielkie cztery wiatry](pattern-3.3.4) — [hl]**400**[/] (limit wykazowy)
- [**3.4** Same honory](pattern-3.4) — [hl]**320**[/] (limit wykazowy)

[muted][3.1](pattern-3.1), [3.2](pattern-3.2), [3.3](pattern-3.3) i [3.4](pattern-3.4) to osobne serie.[/]
