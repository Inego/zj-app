# Smoki

**3.2** · 三元

Kombinacje smoków: dwie grupy smoków plus oczy ze smoków (małe) lub trzy trójki/Kongi smoków (wielkie). Zawsze doliczaj również [Punktowany honor (3.1)](pattern-3.1).

## Układy

- [**3.2.1** Małe trzy smoki](pattern-3.2.1) — [hl]**40**[/] (zawsze +2×[3.1](pattern-3.1) → ≥60)
- [**3.2.2** Wielkie trzy smoki](pattern-3.2.2) — [hl]**130**[/] (zawsze +3×[3.1](pattern-3.1) → ≥160)
