# Ukryta ręka

**1.2** · 門前清 · [hl]**5 punktów**[/]

[Ręka regularna](rules-hands) **bez [otwartych układów](rules-concealed-open)** przed wygraną. Wygrana ze zrzutki jest dozwolona. **[Zakryty Kong](rules-kong-types)** nie narusza tego układu; otwarty Kong go narusza.

Ręce nieregularne ([kategoria 10](pattern-10)) **nie naliczają** Ukrytej ręki.
