# Oczy (para)

Dwa **identyczne** kamienie zamykające rękę regularną („para” / „oczy”).

:::center
{55s} · {WW}
:::

Oczy **nie** są grupą. W [ręce regularnej](rules-hands) potrzebujesz dokładnie jednej pary (chyba że wygrywasz ręką nieregularną, taką jak [Siedem par](pattern-10.2)).

Oczami może być dowolny wzór — liczby, [wiatry](rules-winds) lub [smoki](rules-dragons). Niektóre układy punktowe zależą od tego, jakie kamienie tworzą oczy (na przykład oczy z honorów uniemożliwiają [Bez krańcowych (1.3)](pattern-1.3)), lecz sam kształt ręki wymaga po prostu jednej pary.
