# Układy i oczy

**Ręka regularna** składa się z **grup** (układów) oraz **oczu** (pary). Zobacz [Ręce regularne i nieregularne](rules-hands).

Każda grupa to jeden z trzech typów:

- **[Sekwencja](rules-sequence)** — trzy kolejne liczby w tym samym [kolorze](rules-suits)
- **[Trójka](rules-triplet)** — trzy identyczne kamienie
- **[Kong](rules-kong-types)** — cztery identyczne kamienie, zgłoszone

Oraz para zamykająca rękę:

- **[Oczy](rules-eyes)** — dwa identyczne kamienie (nie tworzą grupy)
