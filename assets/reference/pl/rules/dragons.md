# Smoki

Trzy wzory **[honorowe](rules-honors)** — nienależące do [kolorów](rules-suits) liczbowych:

:::center
{P}{F}{C}
:::

- **Biały** (白) — {P}
- **Zielony** (發) — {F}
- **Czerwony** (中) — {C}

Smoki nie mają wartości liczbowej ani kolejności. Nie mogą tworzyć [sekwencji](rules-sequence) — jedynie [trójki](rules-triplet) lub [Kongi](rules-kong-types) z **tego samego** wzoru (trzy Czerwone smoki, a nie „po jednym z każdego smoka”).

Dowolna trójka lub Kong smoków jest zawsze [Punktowanym honorem (3.1)](pattern-3.1) (+10 za każdą grupę) dla każdego gracza.
